## 不混淆的三类材料

1. **历史证据**：`design/verification/`、`design/releases/` 及旧开发记录保留当时事实；其中旧模式名不是现行需求。旧方案正文可由 Git 历史读取，不需要保存第二套可继续实施的旧方案。
2. **真实运行规范**：当前基线仍从 `design/runtime/` 和部分 capability/task 文档加载指令。不能在递归端口尚未接通时先改成“允许成员派发”，否则模型收到不存在的能力说明。工程交接 §3.5 列出随执行实现同步迁移的资产；后续若路径已迁至 assets，以实际加载路径为准。
3. **当前实现说明**：`src/` 契约、README 中的现行能力及带日期实施切片不被改写成“已经支持递归”。对应源码变更时同步更新。未跟踪的品牌素材和领域引擎草稿不属于本轮编辑范围。
