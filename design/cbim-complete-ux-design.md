# CBIM 全界面 UX 与统一设计语言

## 引擎入口调整（2026-11-15）

对话窗的引擎下拉菜单统一承担选择、安装和更新，不设引擎设置分页或独立安装页。默认展示 Pi、Claude Code、Codex 全部支持项，各行显示当前/目标版本和“可安装、可更新、已安装、正在准备、失败、不可用”。安装与选择分离：点击安装不切换配置，完成后才可选择，正在运行的任务保持原版本。准备期间显示真实环形百分比，未知时显示不定进度；关闭后重新打开继续读取原任务，不重复派发。失败在原行解释并提供重试，键盘 Escape 返回触发器，手机菜单不横向溢出，遵循减少动效设置。模型供应商仍在设置中管理。

可更新仅指当前应用签名清单中的兼容引擎目标，不承诺任意上游最新版。旧冷壳缺少管理端口时明确提示更新应用；开发态显示“随应用提供”。应用版本更新保留原入口，但不再重复展示引擎准备进度。实现与验证见 [开发记录](development-log.md)，未发布版本不视为已安装用户生效。

本文补齐此前只统一外观、没有逐页展开的界面。覆盖依据为当前 `src/view` 的 TSX 页面和操作面；共享消息、附件、工具记录等归入所属页面，不人为将每个组件算成一张独立产品页面。页面编号是评审索引，不是开发清单；实施进度仍以 GitHub Issues 为准。

**本轮优先范围是原有界面。** 原型包含 34 个现有操作面的重设计、1 个共用设计语言目录和 7 个单独标记的聚合/扩展提案，合计 42 个评审页。默认导航只显示原有操作面与规范；新增提案不计入“原有界面已补齐”的范围。逐页设计覆盖不等于所有生产页面已经实施或通过验收。

## 1. 产品边界与交付口径

CBIM 是本地／多端 AI Native 工作流工具。用户与主 Agent 在连续对话中交互；任意 Agent 可通过普通工具调用其他 Agent，结果返回直接调用方。Team 仅配置可调用 Agent 的职责、能力与权限。详细契约见 [产品需求](agent-tool-product-requirements.md) 与 [交互规范](agent-tool-ux-design.md)。

本稿将界面分为三种：

- **现有面重设计**：已有相应业务能力，设计布局及交互，不宣称原型已接通产品。
- **聚合提案**：已有分散数据，需要新增聚合页面或查询契约，例如成果中心。
- **扩展提案**：当前尚未接入的能力，例如外部协作连接器和通知聚合；不自动扩大实施范围。

原型全部使用公开虚构数据，不连接工作区、账号、模型或网络；操作只改变当前页面的演示状态。真实提交、安装、发送消息、授权和终端执行均不存在。首次引导不索取真实密钥。手机布局表示同一页面的响应式设计，不承诺移动客户端或远程执行。

## 2. 全局信息架构

### 固定区域

| 区域 | 设计职责 | 规则 |
| --- | --- | --- |
| 侧栏 | 项目、对话及功能导航 | 工作入口在前；管理入口按职责分组；保留搜索；不用长工具清单阻挡开始任务 |
| 顶栏 | 当前项目、页面、身份/范围、帮助 | 项目身份始终可定位；不因失败偷偷切换项目、模型、连接或负责人 |
| 主工作面 | 当前目标和必要决定 | 页标题 + 一句话用途 + 一个主操作；次要操作不与主操作争抢 |
| 检查面板 | 文件、差异、证据、身份等上下文 | 用户显式打开；关闭后不被新事件自动重开；返回保留筛选、草稿和阅读位置 |
| 局部反馈 | 就地错误、保存结果、等待原因 | 错误留在操作旁；短 Toast 只用于复制等无须决定的结果 |

### 统一页面骨架

列表页：标题/主操作 → 搜索/筛选 → 关键摘要 → 可扫描列表 → 选择详情。编辑页：对象身份/版本 → 分组字段 → 行内校验 → 固定保存与取消。详情页：状态/责任 → 当前事实 → 证据/历史 → 允许的下一步。工作页：目标 → 过程 → 未决事项 → 输入/成果。所有业务专业面使用同一骨架，但不强行改成相同卡片。

### 导航与返回

浏览页面不停止任务、不发送补充。修改草稿后离开：保留编辑 / 放弃本地改动；原型使用离开确认，正式产品需按已有持久能力决定是否提供“保存草稿”。回到原对象必须核对工作区、对话、调用及对象标识；对象不存在时显示原因，不跳到另一个同名对象。全局搜索返回来源路径，跨项目结果有清楚的项目标识。

## 3. 统一设计语言

### 品牌与视觉

设计关键词：清楚、安静、可信、有协作感。保持现有 CBIM 标志；Agent 与普通工具采用同一线性图标语言，不以人格头像替代工具身份。背景分画布、面板、局部高亮三层；主动作中性高对比，警告和失败才使用语义色。不为每个功能另设品牌色，不把所有内容装进大卡片。

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| canvas | #F7F8FA | #17191D | 全局背景 |
| panel | #FFFFFF | #202329 | 内容与表单 |
| subtle | #ECEEF2 | #2A2E36 | 次级区域 |
| text | #20242C | #F0F2F5 | 正文 |
| muted | #596270 | #ADB5C2 | 次要文字，不用于禁用理由隐藏 |
| line | #D8DDE5 | #414854 | 非交互分隔 |
| control | #7D8796 | #7F8A9A | 控件边框 |
| focus | #2459BC | #9BBDFF | 键盘焦点 |
| warning | #8C4A10 | #F0B575 | 等待决定、受阻 |
| success | #246642 | #88D0A2 | 已确认的通过 |
| danger | #B13737 | #FFAAAA | 失败、破坏性操作 |

正文 14px/1.65，窄窗口 15px；辅助信息最低 12px，字段标签 13–14px，区块标题 18px，页标题 24px。间距 4/8/12/16/24/32/48；控件圆角 10px、弹窗 16px、微型标记 6px。普通按钮高至少 36px，触屏至少 44px；密集技术记录可紧凑，但不缩小操作目标。

图标复用 24px 网格、1.75px 圆端笔画、currentColor 的母版；尺寸 14/16/18/20/24px。图标和文案共同表达状态；图标按钮必须有可访问名称。角色、动作、状态是三套语义：停止请求不等于已停止，运行结束不等于验收通过，交接失败不等于对方离线。新增领域图标先登记母版，不能使用随手拼出的 Unicode 图形。

### 组件契约

| 组件 | 交互与状态要求 |
| --- | --- |
| Button | 主/次/文字/危险四级；提交期间保留宽度和动作文字；禁用理由邻近可见；不能仅用 Tooltip 解释关键限制 |
| Field | 标签、帮助、错误各有位置；错误绑定字段；提交失败保留输入；凭据使用专门连接流程 |
| Status | 图标 + 文案 + 适用对象；未知结果与失败分开；时间戳写“最后确认”，不装作实时 |
| List/Row | 名称、状态、责任、更新时间、主要入口；整行打开详情时不嵌套另一整行按钮；菜单保留键盘路径 |
| Dialog | 明确标题/影响范围；原生焦点约束；关闭/Escape 返回入口；有未保存输入时先确认丢弃 |
| Drawer | 补充阅读而非第二套任务；窄屏使用全宽；关闭返回来源，不重置列表筛选 |
| Tabs | 同一对象的不同视图；箭头键/Home/End 切换，aria-selected 真实；导航到新对象不用 Tab 冒充 |
| Toast | 非关键短反馈 4.5s；危险、失败、部分完成和待决定信息常驻 |
| Tooltip | 悬停 450ms、离开 120ms，可移入；键盘聚焦显示，Escape 关闭；边缘避让；滚动/状态变化关闭 |
| Help | 触屏用显式“操作说明”；提示不读取输入值，不暴露凭据；关键流程直接在正文说明 |

### 动效矩阵

| 触发 | 表现 | 时长/限制 |
| --- | --- | --- |
| 悬停/按压 | 背景、边框或 1px 位移 | 120ms；不改变布局 |
| 页面与详情进入 | 透明度 + 3px 位移 | 180ms；不在轮询时重播 |
| 弹窗/抽屉 | 透明度 + 12px 位移 | 220ms；焦点同时正确进入 |
| 状态发生变化 | 文案更新 + 小幅淡入 | 180ms；失败不抖动，成功不撒花 |
| 工具展开／返回 | 原工具条目展开正文或切换全宽详情 | 120–180ms；不重演历史，不移动人物 |
| 加载 | 明确加载文字 | 无总量不显示假百分比；旧数据可保留但标明过期 |

缓动统一 cubic-bezier(.2,.7,.2,1)。prefers-reduced-motion 优先，停用位移和循环动画，状态与因果仍可理解。原型额外提供“减少动效”开关，不能覆盖用户系统的减少动效偏好。

| ID / 页面 | 信息布局、主要操作 | 异常、返回与边界 |

| 01 start 首次引导 | 三步：选择已有项目 → 检查模型配置 → 建立第一个主 Agent 对话；进度和将产生的本地文件说明常显 | 模型不可用时保留项目；可暂缓配置后浏览；未完成时不声称可执行；首次引导完整流程是提案 |
| 02 projects 项目管理 | 最近项目列表；路径、最后使用、状态；主操作添加项目；详情容纳重定位/移除登记 | 路径失效留在原行；重定位要求核对原项目；移除登记说明不会删除业务文件及哪些任务会停止 |
| 03 offices 对话列表 | 项目内主对话、最近回复、执行状态；新建对话 | 空态引导首个指令；旧路由 ID 仅供兼容，不引入办公室层级 |
| 04 chat 主对话 | 用户指令、Agent 回复、普通工具与 Agent 工具连续展示；底部唯一输入框 | 补充默认继续当前对话；不隐式新建任务；草稿、附件和滚动位置保留 |
| 05 topics 工具记录 | 当前对话工具调用列表，按稳定调用身份定位原消息 | 替代原频道与队列入口；记录查询失败不触发重新执行 |
| 06 office 工具执行详情 | 从原工具条目展开输入、过程、结果及约束；Agent 工具显示执行对话 | 不再展示人物协作剧场；深度、并发、预算超限就地返回普通工具错误 |
| 07 graph 任务依赖图 | 可读节点、方向与依赖、选中节点详情；定位主 Agent；历史折叠 | 不缩小字体塞满图；画布可局部平移；缺失引用就地解释；窄屏提供列表替代 |
| 08 member 执行 Agent 对话 | 调用方指令、执行回复、普通工具与递归 Agent 工具；只读 | 无用户直发输入框；补充或提问只路由直接调用方；返回恢复原工具位置 |
| 09 task 任务详情 | 目标→负责人与冻结模型→进度→依赖→候选→验证→历史；只暴露当前允许操作 | 候选不等于验收；检查点/求助/撤销各有真实依据；失败保留已产生的修改及证据 |
| 10 decision 待决定事项 | 具体问题、选项差异、影响范围和证据；选择后单次提交；原决定可对照 | 超时/响应丢失先查询原请求；不可把重新考虑与重发相同命令混淆；不增加无必要审批 |
| 11 recovery 恢复与核实 | 原任务、原请求、已知副作用、未知项；主操作核实原回执；补偿需先预览 | 结果未知不盲重试；没有可靠恢复入口就创建关联核实任务，不伪装原地续跑 |

| 31 settings 设置总览 | 外观、模型、执行额度、网页/反馈连接、资源仓库；显示作用范围 | 分组独立保存；只有用户明确选择才设长期默认；当前任务绑定不随默认值静默改变 |

| 33 budget 执行约束配置 | 在既有设置中管理深度、并发、预算及作用范围；后续调用生效 | 运行时数值与超限错误只在工具条目展示，不新增限额页面；未知费用不显示零 |
| 34 security 网页与反馈连接 | 搜索策略、Brave 开关、GitHub 连接与外部数据范围；显式连接/断开 | 授权网页完成不等于本机已保存；保留等待/失效状态；说明具体发送的数据，不扩大授权 |
| 35 diagnostics 工作区诊断 | 身份/路径/实例、环境检查、可读日志摘要、知识问题；重查当前对象 | 诊断不自动修复未知副作用；日志复制需脱敏；版本/执行权限错误提供具体下一步 |
| 36 terminal 终端 | 固定项目和工作目录、命令输入、输出/退出码、停止；风险邻近输入 | 未退出不显示结束；停止请求不是物理退出；原型不执行任何命令；输出局部滚动 |
| 37 browser 浏览器工具 | 地址、加载状态、页面预览、来源/权限说明、外部打开 | 加载失败保留地址；不能加载的页面提供明确原因；网页内容不当成 Agent 指令 |
| 38 updates 更新 | 当前/目标版本、校验与下载进度、错误、安装影响；仅就绪后允许安装 | 真实进度才显示百分比；稍后不排队安装；正在执行/未保存编辑的处置遵循后端规则 |
| 39 search 全局搜索 | 查询、范围、类型过滤，带项目/对话来源的结果，定位命中上下文 | 聚合提案；权限过滤在服务端；无结果保留查询；索引过期要标记，不能假设跨项目可见 |
| 40 inbox 集中待办 | 需要决定、交接、异常、通知四类；紧急程度和阻塞影响；进入原事项处理 | 扩展提案；已读不等于已解决；去重按真实事项 ID；过期动作失效并给出新来源 |
| 41 people 外部协作连接器边界 | 说明 Git、P4、飞书等未来对接来源、账号与授权边界 | 不建设 CBIM 多人邀请、在线状态和协作服务；这里只解释未来连接器边界，无发送按钮 |
| 42 style 设计语言目录 | 主题、图标、状态、组件、动效、帮助、可访问性规则可对照 | 评审工具；不出现在普通用户任务主流程；系统减少动效优先 |

## 8. 外部协作边界

工程多人协作由未来插件与连接器承接。CBIM 内部只维护 Agent 调用关系，不增加真实人员账号系统、评论、邀请或在线状态。连接器的读写、授权与结果仍使用普通工具调用；外部消息发送遵守明确授权，不把 Agent 输出自动外发。

## 10. 所有页面的状态与恢复合同

| 状态 | 展示 | 可用操作 | 必须保留 |
| --- | --- | --- | --- |
| 正常 | 当前对象/范围/最后确认时间 | 当前允许的主动作 | 身份与版本 |
| 加载 | 具体正在读取什么 | 可离开；不可重复提交 | 查询、旧数据及过期标识 |
| 空态 | 尚未配置/无内容 | 对应的创建或配置入口 | 所选范围；无结果与未创建区分 |
| 无权限 | 缺少哪项能力、作用对象 | 查看已有证据/申请明确范围（若支持） | 不泄露不可见正文 |
| 失败 | 哪一步失败、已发生什么 | 安全重读或已证明可重试的动作 | 草稿、原请求、失败记录 |
| 部分完成 | 已完成/未完成分列 | 查看成果、处理剩余项 | 不显示整体成功 |
| 结果未知 | 等待核实原回执 | 查询原请求；不重放未知写入 | 命令 ID、版本和目标 |
| 版本冲突 | 基线与当前版本区别 | 对比、保留草稿、重新预览 | 不直接覆盖 |
| 完成 | 本次动作完成的精确对象 | 查看记录/返回 | 不扩展为整体目标完成 |

原型每页可切换“正常/加载/空态/受阻/部分完成/结果未知/版本冲突”，并显示页面自己的恢复建议。用于评审，不是后端事实。编辑类主操作显示校验/预览，未知时只能核实；切换状态本身不执行操作。

## 11. 窄窗口与可访问性

- 320–599px：侧栏折叠为显式导航；主面单列；详情全宽弹窗；长路径换行；列表保留名称/状态/主操作，次要元数据进入详情。
- 600–999px：导航可收起，双栏在容器空间不足时改单列；不只根据整窗宽度推断右侧面板可用宽度。
- 1000px 以上：主面与检查面板可并列，正文宽度受限；图/终端可在自己的画布内平移或滚动，不撑宽整个页面。
- 焦点顺序：导航 → 页标题/主动作 → 筛选 → 内容 → 详情；打开对话框进入标题或首字段，关闭返回原入口。错误摘要可定位字段。
- 图标装饰性隐藏；状态有文字；实时进度使用 polite，仅阻塞错误需要 alert；避免每轮 Token 更新打断读屏。
- 减少动效不减少信息；键盘、200% 缩放、读屏和高对比度均是实施验收项目，文档本身不代表已通过。

## 12. 原型使用与评审标准

使用左侧搜索／分组切换既有评审入口；顶栏预览状态、主题和减少动效。主对话、执行 Agent 对话与工具详情遵守同一工具调用模型；真实人员页改为外部连接器边界说明。其他管理页保留现有布局。所有数据与动作明确标记为演示，表单草稿只在本次打开期间保留。

评审时逐页回答：能否识别当前项目和对象？是否知道接下来做什么？失败后是否知道已发生什么？能否在不丢草稿的情况下查看证据？停止与已停止是否区分？未知结果是否禁止盲目重发？同一图标/颜色是否始终表达同一语义？窄屏是否能完成同一设计流程？

本轮只补齐设计材料与评审原型，不修改产品源码、不恢复执行权限、不声称已完成真实桌面验收，也不自动发布或发送人员邀请。

## 13. 版本与验证边界

本次按统一 Agent 工具模型替换旧频道、多人交接和团队聊天设计。先前 42 页／294 组合／1176 窄屏组合等记录属于旧版原型，可通过 Git 历史查阅，不能当作本次替换后的验收证据。
