# CBIM 图标、动效与提示系统

日期：2026-11-15。性质：设计规范与统一 Agent 工具原型母版。后续产品界面实施见 [实施验证](verification/ux-interface-20261115.md) 和 [继续验证](verification/ux-completion-20261115.md)；完整桌面验收仍有 [未完成项](verification/ux-desktop-20261115.md)，原型覆盖不等于产品验收通过。

关联：[UX 主方案](cbim-ux-system-proposal.md) · [图标与反馈预览](cbim-ux-prototype.html#icons-view) · [递归工具调用](cbim-ux-prototype.html) · [SVG sprite](cbim-icon-sprite.svg)。

## 1. 目标与交付范围

建立可持续扩展的一套 **CBIM Outline**：状态、操作、导航、岗位共用几何语言；Tooltip 解释影响与前置条件；动效让状态变化可感知。参考 Cindy 的克制与语义一致性，保留 CBIM 团队责任及证据驱动的工作方式。

当前图标母版保留 70 个命名 SVG，供状态、工具、操作与管理入口复用。Agent 工具只更换工具名称和图标，不另建团队状态体系；图标存在不代表能力已实施。

范围只在设计资料与原型中，不改产品业务状态、权限或源代码。交互控件的图形不会改变其授权与副作用。

## 2. 几何与视觉规则

| 项目 | 规范 |
| --- | --- |
| 母版 | `viewBox="0 0 24 24"`，关键路径通常内缩 2px；描边计入外接尺寸 |
| 描边 | 1.75 单位，圆端点、圆转角；不混用厚重实心与细线图标 |
| 填充 | `fill="none"`，线条 `stroke="currentColor"`，不写死品牌或状态色 |
| 尺寸 | 14px 用于密集辅助行；16px 用于标签/页签；18px 用于默认按钮；20–24px 用于主状态与目录 |
| 对齐 | 随字号等比缩放；图标与文字间距 6–8px，紧凑控件可为 4px；垂直光学居中 |
| 触控区域 | 图形尺寸不等于可点击尺寸：桌面目标 36px，触控目标至少 44px |
| 选中 | 保留图形，通过容器边框/底线/背景及 `aria-pressed` 表达；不切换到另一套填充图标 |
| 禁用 | 整个控件禁用与降强调，保留名称和图形；必须有可访问的原因 |
| 品牌 | 不重绘 CBIM 标志；人物插画不是界面图标，不强制塞进 24px 母版 |

色彩跟随 UX 主方案的语义令牌。普通操作使用正文色；只有已确认通过才使用成功色，阻塞/等待使用提示语义，失败与待核实使用问题语义。状态同时提供文字，灰度下仍能区别。

## 3. 图标清单与语义

### 状态（15）

| 名称 | 含义与图形 | 不应误用为 |
| --- | --- | --- |
| `running` | 圆框播放符：执行中 | 已成功 |
| `queued` | 时钟：排队或等待依赖，文字区分具体等待 | 失败 |
| `decision` | 对话框问号：需要决定 | 工具出错 |
| `verifying` | 放大镜与勾：正在验证或复验 | 验证已经通过 |
| `success` | 圆框勾：明确的通过证据 | 模型回合结束 |
| `delivered` | 包裹与勾：已汇总交付 | 仅上传成功 |
| `stopping` | 未闭合回转线与方块：停止请求处理中 | 已停止 |
| `stopped` | 圆框方块：执行已停止 | 文件已撤销 |
| `blocked` | 沙漏与阻挡线：依赖阻塞 | 普通后台运行 |
| `conflict` | 交叉分向线：方案分歧待协调 | 所有失败 |
| `unknown` | 圆框问号：结果待核实 | 确认失败或建议直接重试 |
| `failed` | 八角框叉：确认失败或拒收 | 关闭面板 |
| `notRun` | 圆框横线：未执行或尚无证据 | 已通过 |
| `rework` | 工具形：返工修复 | 未经授权修改 |
| `archived` | 归档盒与勾：已归档 | 当前仍在运行 |

原型任务映射：目标确认 → `goal`；规划 → `list`；设计对齐 → `design`；接口对接 → `api`；实现 → `code`；恢复执行 → `running`；其余状态使用上表。角色等待与岗位身份分别由状态文字和岗位入口呈现，不能以岗位图标代替业务结论。

### 操作（31）

| 组 | 名称 | 使用边界 |
| --- | --- | --- |
| 执行控制 | `play`、`pause`、`stop`、`next`、`replay` | 播放、暂停、请求停止、下一步、重播；`replay` 只重置演示，不能暗示真实任务可任意重放 |
| 输入与列表 | `send`、`enqueue`、`edit`、`add`、`remove` | 发送、入队、补充、创建、移除；移除排队项不停止当前执行 |
| 审阅与恢复 | `inspect`、`confirm`、`resolve`、`retry`、`unblock` | 检查、确认、协调、重新交接、补齐依赖；未知结果先检查，不能先重试 |
| 页面控制 | `close`、`chevron`、`search`、`menu`、`more`、`openExternal` | 关闭、展开、搜索、导航、更多、外部打开；右侧内部面板不使用外部跳转图标 |
| 外观预览 | `moon`、`sun`、`phone`、`desktop` | 表达点击后的目标模式；Tooltip 同步说明范围 |
| 文件与通用 | `refresh`、`copy`、`download`、`upload`、`attachment`、`undo` | 刷新数据不代表重试执行；撤销只对确实支持的操作出现 |

### 导航与内容（18）

`conversation` 工作台/对话；`team` 可调用 Agent 配置；`office` 历史兼容标识，不作为当前主流程入口；`list` 任务列表；`folder` 工作区/成果；`palette` 风格；`goal` 目标；`handoff` 交接物；`knowledge` 知识；`info` 操作帮助；`settings` 设置；`connector` 连接器；`workflow` 自动化；`terminal` 终端；`browser` 浏览器；`history` 执行历史；`notification` 通知；`diff` 变更。

### 岗位（6）

`person` 用户/成员；`coordinator` 协调；`design` 设计；`code` 实现；`api` 接口；`tester` 验证。这些图标只帮助识别能力与调用对象，不授予额外执行权限，也不表达多人在线状态。

## 4. 控件组合

- 主要操作采用“图标 + 动词 + 必要对象”，例如停止当前执行、查看变更。图标不替代影响说明。
- 纯图标按钮仅用于含义清楚的辅助操作，具有 `aria-label`、可见焦点和 Tooltip；手机另有显式说明入口。
- 图标和文字同义时 SVG 使用 `aria-hidden="true" focusable="false"`，避免读屏重复播报。纯图标按钮的可访问名称放在按钮上。
- 状态文字作为主信息，图标作为辅助辨认。动态状态通过既有 live region 播报，人物动画每一帧不播报。
- 原生 select、checkbox、radio 保留宿主键盘与触控交互，不把任意 SVG 放进 option 或伪造失去语义的选择器。
- 图标可做轻量旋转来表达展开方向；不通过持续旋转、闪烁或跳动制造虚假忙碌。

## 5. 动效系统

| 反馈 | 时长/幅度 | 含义与实现 |
| --- | --- | --- |
| 按钮悬停 | 120ms | 表面、边框和透明度过渡，不放大布局 |
| 按下 | 1px 下移 | 触发反馈；不用于表示执行成功 |
| 视图切换 | 180ms / 3px | 新工作面淡入，保留草稿和业务状态 |
| 任务状态变化 | 180ms / 2px | 仅状态文本改变时强调一次，重复渲染不重复闪动 |
| 侧边模态进入 | 220ms / 12px | 显示详情，退出即时；原生 dialog 维持语义 |
| 展开内容 | 180ms 淡入 | 内容出现；折叠即时，箭头旋转 150ms |
| 轻量通知 | 180ms / 5px；展示约 4.5 秒 | 仅非关键反馈，错误/阻塞原因仍常驻 |
| Tooltip | 120ms 淡入 | 次级解释，不抢焦点 |
| 人物交接 | 随模拟节奏，最长 3.6 秒 | 可关闭的演示叙事，与真实任务状态隔离 |

时长令牌：`--motion-fast:120ms`、`--motion-normal:180ms`、`--motion-panel:220ms`；曲线 `cubic-bezier(.2,.7,.2,1)`。不因动效推迟状态更新或锁住操作，不把动画结束当作任务完成。

**减少动态：** 尊重 `prefers-reduced-motion`，并在风格页提供仅本页的“减少界面动态”。任一开启时关闭界面进入/展开/状态变化动画和人物走动，立即完成视觉变化，全部信息仍可读；操作系统要求优先，用户不能从本页强行覆盖。关闭后人物走动仍需显式重新开启，避免恢复出乎意料的动作。改变动画偏好不停止任务或模拟步骤推进。

不采用错误抖动、成功彩纸、持续呼吸背景或伪进度百分比。真实耗时未知时直接说明当前动作。

## 6. Tooltip 与操作说明

### 内容

Tooltip 解释“做什么、作用于谁、什么不代表成功、为什么不可用”，不只是重复按钮名。

| 触发项 | 示例文案 |
| --- | --- |
| 停止当前执行 | 请求停止当前执行，保留已发生的改动；不等于撤销。 |
| 关闭详情 | 关闭详情，回到原页面；不会停止或撤销工作。 |
| 重播此情境 | 仅用于旧演示兼容；真实未知结果不得重放。 |
| 阻塞时的下一步 | 当前为依赖阻塞。请在任务状态区完成对应处理，不能跳过。 |
| 结果未知时的停止 | 结果未知，先核实已发生的改动，不能重复停止或执行。 |
| 加入队列 / 提交补充 | 复用输入框当前的真实影响说明，不能固定写成“发送”。 |

### 行为

- 鼠标停留 450ms 后出现，快速经过不闪现；键盘焦点可触发。离开延迟 120ms，允许移入提示阅读；提示没有交互按钮。
- `role="tooltip"`，触发元素以临时 `aria-describedby` 关联。关闭时恢复原有描述，不覆盖其他辅助说明。
- Escape 关闭当前提示；若在模态内，先关闭提示，再按 Escape 才交给模态退出。提示不抢焦点。
- 定位随触发项，在视口边缘翻转并限制宽度；滚动、尺寸变化、操作触发和内容更新时关闭过时提示。
- 禁用按钮保留真实 `disabled`，外层使用可聚焦的说明区域呈现原因，不把禁用按钮改成可点击。
- 触屏不依赖悬停或长按。顶部“操作说明”列出当前可见操作的含义与禁用原因；查看说明会暂停模拟，关闭后手动继续。
- 关键异常、恢复前提、破坏性影响必须在正文/确认流常驻，Tooltip 不能成为唯一入口。

## 7. 资产与维护

原型的 `UI_ICONS` 是当前设计母版的唯一人工维护来源。SVG sprite 由 [生成脚本](build-cbim-icon-sprite.mjs) 导出，不手工修改：

```sh
node design/build-cbim-icon-sprite.mjs
node design/build-cbim-icon-sprite.mjs --check
```

示例使用（正式接入还需遵守产品组件与主题约束）：

```html
<button aria-label="停止当前执行">
  <svg viewBox="0 0 24 24" width="18" height="18" aria-hidden="true">
    <use href="cbim-icon-sprite.svg#cbim-stop"></use>
  </svg>
</button>
```

原型仍为单 HTML 文件，内联使用母版，不依赖外部 sprite、字体、CDN 或脚本。独立 sprite 用于开发交接；本地 `file:` 跨文件引用可能受浏览器限制，可将 symbol 内联或通过项目的本地服务使用。

新增图标流程：先确认没有同义图标 → 写清语义与误用边界 → 按母版绘制 → 检查 14/16/18/24px 与深浅色 → 更新目录与 sprite → 验证按钮名称及 Tooltip。不要用新图标掩盖含糊业务状态。

产品迁移应复用产品既有图标组件并逐项替换，不把整个原型脚本直接导入产品，也不建立第二套业务状态来源。实际开发仍通过独立 Issue 推进。

## 8. Agent 工具调用的统一映射

主 Agent 和执行 Agent 共用对话图标；Agent 工具与命令工具共用展开、状态和结果组件。递归深度、并发和预算使用普通详情字段，超限用现有失败图标、文字和结构化原因，不新增专属徽章体系或页面。等待调用方答复沿用等待状态；等待用户决定由主对话呈现。

展开／收起 120–180ms，手机全宽详情返回恢复原阅读位置；系统减少动效下禁用位移和循环动画。Tooltip 支持键盘和 Escape，触屏关键操作必须有可见文字。

## 9. 验证边界

原 18 步办公室模拟已被统一工具调用原型替换；旧浏览器检查属于历史，不作为新版验收。母版仍由 UI_ICONS 生成，必须用生成器 --check 核对；新版主对话、递归工具、错误和只读执行详情另行验证。设计检查不等于真实执行、产品测试或桌面通过。
