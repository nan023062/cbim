# CBIM UX 与风格系统设计

日期：2026-11-15｜版本：2.0｜目标设计，不代表产品已实施。

## 1. 产品模型

CBIM 是本地／多端 AI Native 工作流工具。用户与主 Agent 在连续对话流中交互；执行 Agent 与直接调用方 Agent 交互。任何 Agent 都可调用已授权普通工具或其他 Agent，Agent 调用统一呈现为工具调用与结果。

Team 是可调用 Agent 的职责、能力与权限配置，不是另一种聊天模式。没有 Team 配置时主 Agent 仍能直接工作。不提供多人邀请、在线状态或独立协作服务；未来通过连接器对接 Git、P4、飞书等外部工程协作工具。

详细需求以 [Agent 产品需求](agent-tool-product-requirements.md) 为准；逐项交互见 [Agent UX](agent-tool-ux-design.md)，实施边界见 [工程交接](agent-tool-engineering.md)。

## 2. 信息架构

- 导航：项目与对话；配置、资源和设置按需进入。
- 主工作面：用户输入、Agent 回复、工具调用与结果连续展示，底部一个主 Agent 输入框。
- 工具详情：输入、真实进展、结果、错误与实际可用操作。Agent 工具展开后是同样的 Agent 对话流；其内部工具继续使用同一交互。
- 成果：从工具结果或主 Agent 交付回复打开文件、差异和验证记录，保留来源与版本。
- Team 配置：可调用 Agent 的能力、权限、模型及来源。配置变更只影响后续调用，不改变在途绑定。

不再以办公室、话题、成员任务等额外层级组织用户主流程。既有历史缺少调用关系时保持只读可查，不按名称或时间猜测嵌套。

## 3. 完整工作流程

用户提出目标 → 主 Agent 自己调用工具或调用执行 Agent → 接收工具结果 → 判断下一步 → 验证并回复用户。执行 Agent 可递归使用同一流程，输入和结果只面向直接调用方。

执行 Agent 的对话默认只读，不提供用户直发框。用户改变要求仍发给主 Agent，由主 Agent协调；子 Agent 提问先回到调用方，需要用户决定时由主 Agent 正常提问。查看、展开或返回记录不提交指令、不暂停执行。

停止请求向当前调用及后代传播，停止新增派发；仍在退出时显示“停止中”，无法立即取消的真实操作单独说明。未知结果先查询原调用，不自动重复执行。工具完成不等于任务验收通过。

## 4. 工具状态与约束

沿用普通工具的执行中、等待答复、停止中、完成、失败、取消及结果待核实展示，不新增 Agent 专属状态体系。每个状态都有文字、图标与实际依据。

递归深度、并发和预算在工具详情显示当前值、上限、单位和范围。超限返回原工具条目的错误，说明是否开始、已发生改动及可核实记录；不弹出额度中心或生成空频道。调用前预检失败保留输入和原对话。

## 5. 响应式展开

桌面可在原工具条目内展开；较长执行对话进入既有详情容器。手机使用全宽详情，“返回调用方”恢复原阅读位置，避免每递归一次就缩窄正文。主输入草稿、工具展开状态与阅读位置按原对象保留。

## 6. 风格系统：安静、精确、一致且可理解

### 原则

- 中性色承载长时间阅读；主操作使用高对比中性色。品牌与工作状态分离。
- 层级依靠留白、字号、细线和局部表面区分；无装饰渐变、无大面积彩色工作卡片。
- 保留现有 CBIM 标志，正式实现引用 `branding/cbim-mark.svg`，不仿制 Cindy 标志。原型仅使用 CBIM 文字标识。
- 工具状态使用正文一致的线条与语义色；递归调用沿原工具展开，不增加人物剧场作为主要反馈。
- 可用性优先于极简：停止、未决事项与失败原因不能藏在溢出菜单。

### 建议令牌（提案，不代表已迁移）

| 语义 token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `surface.canvas` | `#F7F8FA` | `#17191D` | 全局画布 |
| `surface.panel` | `#FFFFFF` | `#202329` | 输入、弹层、局部成果 |
| `surface.subtle` | `#ECEEF2` | `#2A2E36` | 悬停、次级区域 |
| `text.primary` | `#20242C` | `#F0F2F5` | 正文、标题 |
| `text.secondary` | `#596270` | `#ADB5C2` | 辅助说明 |
| `border.default` | `#D8DDE5` | `#414854` | 非交互分隔 |
| `border.control` | `#7D8796` | `#7F8A9A` | 需独立识别的控件边缘 |
| `action.primary` | `#20242C` | `#F0F2F5` | 主按钮；文字取反色 |
| `status.active` | `#8C4A10` | `#F0B575` | 真实运行状态 |
| `status.success` | `#246642` | `#88D0A2` | 已有证据的通过 |
| `status.danger` | `#B13737` | `#FFAAAA` | 失败、破坏性操作 |
| `focus.ring` | `#2459BC` | `#9BBDFF` | 键盘焦点 |

业务模块不得各自硬编码新色。正式令牌迁移先盘点现有 `--bg / --surface / --line / --muted / --accent` 的真实用途，再建立映射，避免把同一个旧 accent 同时用于品牌、选中和运行状态。

### 排版与尺度

- 字体：系统无衬线（Windows 使用 Segoe UI / Microsoft YaHei，macOS 使用系统字体 / PingFang SC）；不要求联网字体。代码使用系统等宽字体。
- 正文 14px / 1.65；窄屏正文 15px / 1.65；辅助 12px / 1.5；区块标题 16–18px / 500–600；页面标题 22–24px / 600。字重以 400、500、600 为主。
- 间距：4、8、12、16、24、32、48px；正文宽度建议 640–760px，长说明不铺满屏幕。
- 圆角：6px 小控件，10px 输入/卡片，16px 弹层；999px 仅用于状态/标签等胶囊元素。不要所有内容都装进大圆角卡片。
- 桌面普通控件高度 36px，图标按钮至少 36px；窄屏主要触控目标至少 44 × 44px。
- 图标：采用 [CBIM Outline 图标、动效与提示规范](cbim-icon-motion-system.md)，24px 母版、1.75 单位圆端描边，按 14/16/18/20/24px 使用；不可单独用不熟悉图标表达危险操作。
- 动效：交互反馈 120–180ms，面板 180–220ms；仅使用 opacity/transform。系统减少动态时禁用位移动画与循环呼吸，保留完整状态。

### 核心组件及契约

| 组件 | 必须表达 | 变体/边界 |
| --- | --- | --- |
| WorkspaceSwitcher | 当前工作区、可识别路径 | 工作区失效、加载、无项目；不静默替换 |
| ConversationNavItem | 对话名称、真实执行提示 | 返回原对话，不创建频道 |
| ToolStatus | 原调用、真实状态、必要下一步 | 等待调用方与等待用户分开，不显示推测进度 |
| AgentComposer | 主对话草稿、附件与发送对象 | 只有主 Agent 接受用户输入；执行 Agent 对话只读；IME 组合输入不触发发送 |
| ToolCall | 工具名称、目的、真实状态 | Agent 与普通工具同组件；展开执行对话 |
| DecisionCard | 决策对象、选项、影响、处理状态 | 只在显式提交后生效；重复提交不能重复执行 |
| ArtifactPanel | 对象与版本、改动、验证与限制 | 预览/变更/证据；无成果时真实空状态 |
| EvidenceRow | 检查范围、方法、版本、结果 | 通过/失败/未执行/过期；旧证据不沿用到新版本 |
| RecoveryNotice | 已完成、未知部分、合法下一步 | 不提供未实现的继续/撤销 |

## 7. 布局与可访问性

图标、状态反馈、悬停/聚焦提示、禁用原因与触屏替代入口统一遵循 [图标、动效与提示系统](cbim-icon-motion-system.md)。[原型图标目录](cbim-ux-prototype.html#icons) 展示 70 个母版，主题与减少动效可切换；完整管理原型保留 Tooltip 交互示例。各原型的实际覆盖以当前内容为准。

≥1280px：约 224px 导航 + 弹性主区 + 320–400px 可选成果区。960–1279px：保留导航，成果作为抽屉，避免三栏压缩正文。600–959px：折叠导航，单主区。320–599px：单列，成果全屏，导航抽屉；长路径可折行，图表提供列表替代。

主内容先于辅助内容进入阅读顺序。焦点可见，弹层支持 Escape 关闭、焦点约束及关闭后返回触发按钮；抽屉不让焦点落到遮挡区域。草稿与阅读位置按对话／调用身份保留，开关面板不清空。状态通知使用适当的 live region，不逐 token 播报。图形旁有文字，触控不依赖 hover。

目标是 WCAG 2.2 AA：正常文字对比度至少 4.5:1，关键控件/焦点至少 3:1；正式组件上线时测量实际配色与禁用/悬停状态。原型中的配色是候选值，未完成全套无障碍审计。


## 8. 原型范围与评审

[自包含原型](cbim-ux-prototype.html) 使用本地示例，演示主 Agent → 联机 Agent → 测试 Agent 的普通工具调用、逐层详情、只读执行对话、结果回传及深度／并发／预算错误。状态切换只预览示例，不调用模型、修改工程、联网或产生真实计费。

原型支持主题、减少动效、图标目录及主 Agent 输入草稿；所有页面内交互只影响内存。数字不是默认配置。旧办公室人物剧场与多人交接模拟已从当前原型移除，不再作为产品行为依据。

## 9. 验收边界

逐项核查消息来源、调用身份、父级结果路由、错误是否就地可见、停止与退出的区别、手机返回和草稿保留。产品实现须以真实调用链和桌面证据验收；静态原型或设计文档不能证明这些能力已实现。

本次替换的旧设计及旧浏览器验证可通过 Git 历史查阅；其中“18 步办公室剧场”等验证不适用于本版原型。新一轮实际验证由开发记录记载，不复制旧通过结论。
