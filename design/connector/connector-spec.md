# 连接器声明与插件身份映射

CBIM 连接器领域层保存外部工具定义与身份映射，不承担连接、认证或进程生命周期。桌面适配器可明确连接用户已经共享的当前资源仓库并进行真实 HTTP 只读核验；Cindy 外部插件调用、账号接入和运行隔离仍未接通，不能因声明存在就认为已经可以执行。

唯一真源是调用方提供的连接器注册表，遵循 [注册表 Schema](registry.schema.json)。不再为每项建立 connector.json 或 usage.md。

注册表包含 connectors 数组；每项共有 id、name、summary，严格选择以下一个分支：

- Cindy 插件：保留既有 `plugin:{ghost_id,namespace}` 格式，不添加 provider。公开根命名空间用 JSON null，企业命名空间保留实际字符串，不能用字符串 null。
- 资源仓库：`provider:'resource_repository_v1'` 与 `repository:{repositoryId}`，仓库身份为 UUID；不允许混入 plugin、URL、令牌或访问授权。

id 沿用 `.cbim/connectors/<name>` 的稳定逻辑引用形式，不表示目录存在。重复链接器标识或同一提供方目标会被知识校验拒绝；跨提供方的目标不混为同一种身份。

登记 Cindy 插件映射时须核实身份，未来适配器执行前还须核实启用状态、工作区可用性与账号条件。插件安装或可发现不证明全部操作已获授权。注册表不保存凭证、不复制工具 Schema，也不维护第二份插件手册。

Agent 和 Module 的 connectors 列表通过 id 引用声明。插件是团队共享资源，引用不表示独占关系或授予写权限。未映射到真实插件的旧配置保留迁移记录，不伪造插件 id。

资源仓库在桌面上先预览并提交静态定义，再独立允许该工作区只读访问；不能将知识事务与授权存储宣称为原子提交。授权绑定定义哈希与仓库身份，访问前后核对授权版本、共享连接代际和目标；撤销、关闭共享、切换仓库使旧读取失效，不回退本地文件。重启保留记录但不自动开启共享。核验返回最多 20 项摘要，正文不进入当前桌面协议，资源不自动安装或执行。

主 Loop 每轮捕获已就绪授权，提供 `cbim_repository_list`（最多 50 项摘要）与 `cbim_repository_get`（最多 4096 个 Unicode codepoint）。后续分页和正文读取绑定目录版本；正文分块返回完整原文哈希及完整性标记，不冒称全文。调用前后复核原工作区实例、定义、授权和共享代际，取消贯穿 HTTP 正文读取，不自动重试或换源；未共享/未授权的主运行及成员均不装配这两个工具。

真实授权、公开事件及运行回执使用独立 `repository` scope，包含链接器、仓库及连接实例。资料可以进入用户选择的模型上下文，但不是系统指令，也不是业务文件实现、Workflow 验收或文件检查点证据。界面显示真实回执身份；旧日志缺少身份时不补造。适配器可用性、权限与回执由实际实现决定；连接器领域不反向加载 Task、Skill、能力或业务规范。CBIM 不恢复对外 MCP 服务。
