# CBIM 桌面交互设计规范

适用版本基线为 2026-11-20 的新版桌面。本文供产品、设计、前端和测试共同使用，覆盖主窗口、Office、资源页面、设置、扩展面板、资源监视器，以及从这些入口打开的菜单和系统选择器。

**阅读约定**　尺寸均为 100% 缩放下的 CSS px。“应”表示验收目标；“当前预留”表示实现尚未开放。下文给出的键盘行为、错误恢复和窄屏布局也是验收目标，具体版本是否通过以实测为准。

## View 核心 UX 准则：操作图标优先

工具栏和选择器中的配置、管理、更多等常用操作使用框架图标，不重复显示动作文字。图标按钮必须提供简洁的 tooltip 和等义的无障碍名称，并支持键盘访问。选项名称、状态、错误和确认后果保留可见文字，不能要求用户悬停才能辨认。输入窗仅列出本机已安装、已启用且可用的引擎；引擎管理统一在「执行引擎」页。大模型菜单底部保留「大模型设置」。

## 1. 先安排用户的工作路径

用户打开本地目录后，主要工作是在一个 Office 中描述目标、看执行反馈、继续追问。侧栏负责换项目，资源页负责准备工具，设置负责个人配置，监视器负责旁观运行。用户为了安装引擎或配置模型暂时离开 Office 时，返回应落在原项目、原会话和原草稿。

| 表面 | 进入 | 主操作 | 返回或关闭 |
|---|---|---|---|
| 欢迎页、工作区列表 | 首次打开、左栏项目 | 选目录、搜索、打开 Office、新建对话 | 选择已有项目 |
| Office | 项目行、项目“新建任务” | 输入目标、选择引擎和模型、发送或停止 | 切换项目或会话 |
| 资源商城 | 左栏「资源商城」 | 按引擎、连接器、人力和业务浏览，查看版本并安装或导入 | 顶栏返回工作区 |
| 设置 | 左下用户菜单 | 切换主题，配置模型供应商 | 设置左上返回 |
| 扩展面板 | 工作区右上固定图标 | 管理标签、展开或收起 | 同一图标 |
| 资源监视器 | 原生标题栏左上 | 查看虚拟资源和系统进程 | 独立窗口关闭 |
| 帮助、关于 | 标题栏按钮、设置分类 | 阅读对应内容 | 关闭浮层或返回设置 |

## 2. 共用尺寸与视觉层级

| 元素 | 尺寸和排版 | 使用规则 |
|---|---|---|
| 主窗 | 参考画布 1320 × 860；标题栏 32 高；工作区顶栏 44 高 | 系统窗口按钮预留右上空间；可拖动区域避开按钮 |
| 左栏 | 宽度取窗口宽度的 18%，限制在 208–264；内边距约 10 | 项目列表独立滚动；资源入口置顶，用户栏固定到底部 |
| 右栏 | 并排宽度取窗口宽度的 32%，限制在 310–600；标签栏 44 高 | 展开前后，切换按钮的右边距和纵向中心相同 |
| 正文 | 常规控件 14；页标题 20；次标题 16–18；辅助说明 12；紧凑仪表 11–12 | 桌面优先系统中文字体；代码等宽，指标等宽数字。正文行高 1.5，消息 1.75 |
| 间距 | 相邻图标 4；同组控件 8；卡片间 12；卡片内 16；大分组 24–32 | 组间留白大于组内留白；同页标题、正文、底部操作共用左对齐线 |
| 交互目标 | 一般按钮 32 高；导航行 34；表单控件 36；图标 14–16，紧凑图标按钮 28 | 粗指针设备以至少 44 × 44 的可点击区域验收；图形本身可保持原尺寸 |
| 外形 | 控件圆角 6–8，卡片 8–10，输入框 14；区域分隔线 1 | 同级面板以底色和细线分层；阴影用于悬浮菜单和对话框 |
| 焦点与动效 | 键盘焦点环 2，外偏移 3；悬停约 120 ms，浮层约 180 ms，面板约 220 ms | 键盘焦点持续到焦点转移；减少动态效果时直接切换状态 |

深色主题用侧栏 `#111111`、画布 `#191919`、卡片 `#202020`、悬停 `#292929`、选中 `#37383A`、边线 `#353535`。正文 `#C7C7CA`，说明 `#A7A7AB`，标题强调 `#D7D7DA`。浅色使用对应的侧栏、画布、表面、边线和文字令牌；原生下拉、浮层、代码块、独立窗口同步适配。成功、阻碍、失败同时给出文字或图形。普通正文以对比度至少 4.5∶1、焦点和必要图形至少 3∶1 为验收目标。

深色对话窗按用途设置文字亮度：长回复、输入文字、菜单项和侧栏名称使用 `--text`；标题使用 `--accent`；时间、说明和占位文字使用 `--muted`。不要用纯白排长段落，也不要降低整个容器的不透明度来调暗文字。浅色主题独立设色；链接、警告、失败和键盘焦点保留各自的语义色。验收时在画布、卡片和选中行背景上分别检查文字对比度。

## 3. 窗口、滚动与导航

| 可用宽度 | 首次打开 | 手动展开后的布局 |
|---|---|---|
| ≥1380 | 左栏和扩展面板展开 | 中央区使用剩余空间，消息列居中 |
| 960–1379 | 左栏展开，扩展面板收起 | 扩展面板并排，输入工具行可换行 |
| 721–959 | 左栏展开，扩展面板收起 | 右栏覆盖工作区，宽度最多 420 且最多占窗口 90% |
| ≤720 | 两侧默认收起 | 左栏覆盖，宽度最多 270 且最多占窗口 86%；关闭后恢复正文焦点 |
| ≤640 的设置页 | 分类移到顶部 | 分类横向滚动，表单纵向排列，保存键始终可达 |

断点决定初始排版；用户已手动折叠、选标签或填写草稿时，调整窗宽应保留其选择。列表过长时仅列表滚动；Office 仅消息区滚动，输入区固定在底部。长代码和宽表格在内容块内横向滚动。检查中文长项目名、长模型 ID、路径和高 DPI 下的系统窗口按钮。

### 工作区与用户菜单

- 标题栏依次提供侧栏开关、资源监视器、帮助、关于；按钮可键盘触发。帮助和关于允许轻量阅读，点击外部或 Esc 关闭并返回触发按钮。
- 侧栏通过「资源商城」进入四类目录。项目搜索、工作区标题与右端加号、项目列表和用户栏沿用工作区布局；在商城切换分类时保留当前项目。
- 欢迎页居中放品牌图标、标题“打开一个工作区”、一句目录说明和“选择目录”。标题旁加号与欢迎页共用系统目录选择器。取消后保留原项目；选中有效目录后打开该项目的 Office。目录失效时展示具体路径与重新选择入口。
- 项目名左对齐、单行省略，完整名称可查看。鼠标悬停或键盘进入项目行时显示“更多”和“新建任务”；触屏直接可达。右键与“更多”打开同一项目菜单。新建任务创建该项目的新对话；再次点击项目行打开其已有对话。
- 用户栏点击后向上打开菜单，保留“设置”和“检查更新”。外观统一从设置进入。当前应用更新动作预留；正式开放时显示应用版本与更新结果。执行引擎页的“检查更新”专用于插件。

## 4. Office 对话与主 Agent

消息列与输入列共用最大宽度 856，水平留白 12–36。会话头部约 40 高，左侧为 Office 名称，右侧为会话选择器和新建图标。项目标题始终在上一级顶栏可见。用户消息靠右、宽度最多为列宽的 85%；Agent 消息靠左，正文可选择复制。消息间距 28，角色和执行提示使用辅助字号。

```text
Office 对话                                  [会话 ▾] [＋]
──────────────────────────────────────────────────────
                          用户目标
主 Agent
执行反馈和回复正文                         ← 消息区滚动

正在思考…                              24 s · 18 tok/s
╭────────────────────────────────────────────────────╮
│ 输入目标或补充消息                                 │
│ ＋  权限                  引擎 ▾  模型 ▾  发送／停止 │
╰────────────────────────────────────────────────────╯
                                     费用 · 上下文占用
```

| 区域 | 操作与尺寸 | 状态与恢复 |
|---|---|---|
| 输入正文 | 最小高 72，最大约 24vh，可多行；最多 32,000 字符 | 空白草稿禁发；Enter 换行，Ctrl／⌘ + Enter 发送；中文输入法选词期间忽略提交快捷键 |
| 左下加号 | 选择一个文本文件，将文本追加到当前草稿 | 单文件上限 128,000 字节；超限、读取失败或追加超出剩余容量时保留已有输入并说明原因 |
| 左下权限 | 图标展开“只读访问、默认权限、完全访问”，呈现当前选择 | 作用域为 Office。运行中的控件依实际能力锁定；交互应明确新选择从哪一轮生效 |
| 右下引擎、模型 | 并列下拉，显示具体引擎与模型；长名可截断，列表内提供全名 | 新会话预选 Codex；按协议过滤启用的生成模型。无匹配时引导配置供应商；返回原会话保留草稿 |
| 发送／停止 | 同一位置替换按钮；常规鼠标目标约 28，触屏扩大 | 发送须同时满足非空草稿、版本校验通过、引擎启用、模型兼容。发送后禁止重复提交，停止请求等待引擎确认 |
| 框外左上／右上 | 左为简短阶段提示，右为总时长与 Token 速率 | 按真实事件切换连接、思考、输出、完成或失败；短窗尚无速率时显示“—” |
| 框外右下 | 费用和上下文占用同一基线 | 说明币种、Token 容量与比例；未知显示“—”，有实测零值才显示 0 |

历史阅读时，新输出应保留用户当前阅读位置，并提供返回最新消息的方式。失败反馈贴近输入区，说明发生在“引擎准备”“模型配置”或“执行”哪一步；保留可重试的输入。切换引擎只影响后续轮次，原消息顺序和会话归属保持一致。执行明细未来展开时，可展示厂商提供的可见进度、工具调用和结果；缺失的事件不补写成虚构执行记录。

## 5. 资源页面

侧栏「资源商城」默认在「全部」中并列呈现四类商品卡，打开整卡后进入可返回的商品页。商品页显示功能、预览、开发者、更新记录与当前主操作，购买或授权通过确认窗核对范围。页标题取共享 20 px 令牌，表单和按钮沿用客户端字号。活动分类使用选中底色与细暖橙线，悬停和键盘焦点各有独立反馈。返回后恢复商品卡焦点与浏览位置。见[商城交互方案](resource-market-ux.md)。

页宽最多 940，水平内边距 18–38。页标题左对齐，刷新或检查更新位于同一行右侧。卡片最小目标宽 270，可用宽度不足时单列；卡片内边距 16、间距 12。标题、版本说明和主要动作优先于依赖详情。返回按钮位于工作区顶栏，保持原项目和 Office 身份。

### 执行引擎

目录首次加载显示“正在读取引擎目录…”。正式目录与本机安装状态分列呈现；“目录可见”表示用户可以选择安装。每张卡包含名称、当前版本、可用版本、安装或更新、启停、移除，以及可展开的协议、引用、缓存和依赖详情。

| 状态 | 用户看到 | 可执行操作与结果 |
|---|---|---|
| 已登记、尚未安装 | 当前版本“尚未安装”，列出可用版本 | “下载并安装”；点击后只启动一次 |
| 正在下载或校验 | 阶段和真实进度；没有百分比时显示不定进度 | 禁止冲突操作；完成后以宿主确认的活动版本更新卡片 |
| 已安装且为最新 | 当前与候选版本一致，状态“已启用” | 可配兼容模型进入对话；可查看引用或停用 |
| 有兼容更新 | 同时显示本地版与候选版 | 更新并校验成功后开放新一轮发送；失败保留原安装记录 |
| 已停用／正在使用 | 显示停用状态或引用数 | 已停用可启用；使用中限制停用和移除，并解释占用 |
| 网络、签名或宿主异常 | 保留可核验的上次目录，显示原因和重试 | 校验失败阻止激活。区分“目录读取失败”和“仓库没有插件” |

“移除引擎”应说明移除的是本机活动安装，缓存、模型配置和会话历史各自保留。Office 下拉与管理页共用版本和启用状态；从输入框进入管理页，返回后重新读取目录。

### 链接器、人才市场、业务模板

三页共用目录来源、搜索、类型筛选和结果列表。链接器卡以外部工具产品为对象；人才市场以岗位或组织资源为对象；业务模板以项目、工作区和流程模板为对象。卡面依次呈现类别、名字、摘要。当前入口用于浏览，写入、购买和授权动作须有相应业务能力才开放。

搜索应保留原查询。无数据时区分“资源库尚未配置”“仓库为空”“当前条件没有结果”；分别提示配置来源、刷新或清除筛选。刷新失败时保留上次成功结果并标明其时效。

## 6. 设置及模型配置

设置覆盖主内容区。左侧分类宽 200–260，顶部依次为返回、标题、搜索；右侧内容列最大宽 816，垂直滚动。分类行约 34 高，普通设置行至少 52 高，标题和说明位于左侧，选择器或开关置右。说明使用 12 号字，长说明允许换行；输入表单在窄屏改为上下排列。

| 页面或区域 | 元素与行为 |
|---|---|
| 通用 | 顶部本地用户卡；依次列语言、通知、应用行为、离开电脑、消息输入、默认工作目录。当前预留控件显示已有值并禁用；关闭窗口行为等静态值使用正文 |
| 外观 | 深色／浅色单选，即时应用并保存。切换时当前位置、输入值和焦点保留 |
| 模型供应商列表 | 页首“添加供应商”；每行展示供应商名、默认生成模型和默认标记，提供编辑、设为默认、测试与删除相关入口 |
| 编辑供应商 | 名称、协议、服务地址、鉴权与密钥一组；兼容连接单独成组。密钥遮盖；已保存凭据用状态说明。测试结果和校验错误紧邻对应连接 |
| 生成模型 | 发现模型或手工录入；允许启停、选默认、配置上下文和输出预算。发现结果先进入草稿；“同步已有模型能力”解释将修改的字段。保存后供 Office 选择 |
| 向量模型 | 单独列连接、模型和维度；生成与向量分别测试。仅配置向量模型时仍可保存该供应商；Office 对话选择器仅列可生成文本的型号 |
| 帮助、关于 | 侧栏可搜索；右侧显示简短使用说明或产品身份。标题栏浮层使用对应内容的短版 |

编辑时一次只提交一份草稿。保存期间按钮展示进度；失败保留字段，把焦点引向首个错误。取消后清除未保存的凭据草稿。删除供应商需明确目标及对默认选择的影响；取消后回到原条目。遇到 401、协议不兼容、网络超时分别提示检查凭据、切换协议或重试，错误文本不得回显密钥。

当前设置导航还有个性化、用量历史、模型组、语音输入、IM 机器人、键盘快捷键、任务导入、远程连接、共享任务、插件、工具、自动操作和存储空间。这些分类目前预留，显示禁用态。正式接入时须提供字段、保存语义、错误恢复和窄屏验收用例。

## 7. 扩展面板与资源监视器

**扩展面板。** 中央办公室保留对话，组织架构与业务架构在右栏编辑当前项目。默认页签依次为 Web 浏览器、组织架构、业务架构、定时任务、控制台。加号可新开独立网页或恢复已关闭的工具页；工具页不会重复打开。关闭当前页优先选左邻。收起再展开保留页签。窄栏仅标签条横滚。网页支持 HTTP(S) 地址，受网站嵌入策略限制。控制台显示当前对话的执行记录；定时任务页在调度服务接入前显示说明。

**资源监视器。** 从标题栏打开独立窗口，再次触发应聚焦已有窗口。以 580 px 宽验收；标题栏高 40，数据区独立滚动。上部显示总负载、阈值、权重说明及 Token 速率。各组可折叠，组标题带数量；值变化保留折叠状态。下部为真实操作系统进程表，名称列弹性，CPU、内存、PID 的参考列宽为 70、80、64，右对齐。按 CPU 降序，显示单位；零个实例显示 0，首个样本到达前显示等待状态。

| 虚拟资源标签 | 计量 | 更新规则 |
|---|---|---|
| 进程（Agent 实例） | 每个 10 负载 | Agent 创建、忙闲切换、销毁时更新对应项 |
| CPU 核心（引擎实例） | 每个 100 | 按实例实际生命周期计数 |
| 磁盘（Workspace 实例） | 每个 5 | 统计打开的实例，同一模板可产生多个实例 |
| 外设（链接器实例） | 每个 50 | 同一共享实例按实例标识计一次 |
| 流量（Token 速度） | tok/s | 执行时按短滑动窗统计，空闲 Agent 停止窗口计算 |

总负载为各类实例数乘权重后相加，参考阈值 1000。例：2 个 Agent、2 个引擎、1 个工作区、1 个外设，显示 275 / 1000。阈值用于观察；CPU 百分比、系统内存、PID 单独采样。运行时事件局部刷新，系统进程指标低频采样，更新时应保留滚动位置。

## 8. 通用组件状态与无障碍

| 组件 | 可见反馈 | 键盘与恢复 |
|---|---|---|
| 按钮、图标 | 默认显示动作；悬停提高底色；按下给短反馈；禁用降低强调；忙碌保留原宽度 | Tab 聚焦，Enter／空格执行；图标提供可访问名称，如“项目名 · 新建任务” |
| 菜单与浮层 | 锚定发起控件，靠边时翻转；菜单组间用留白或细线 | Esc 或外部点击关闭；关闭后焦点回到发起点。箭头等行为遵循所用原生或菜单组件语义 |
| 单选、下拉、开关 | 显示当前值；选中态与悬停态有区别；不可选项带原因 | 支持系统键盘选择；读屏能读出名称、值及禁用状态 |
| 文本框、搜索、表单 | 持久标签，提示文本只作示例；必填、格式错误紧邻字段 | Tab 按阅读顺序移动；输入法组合期间保留编辑；失败时保留草稿 |
| 列表、卡片、折叠组 | 选中行明确；长标题省略，详情可读全名；数量变化只更新对应位置 | 隐藏的行内操作在行获得焦点后可见；披露按钮能读出展开状态 |
| 进度、错误、确认 | 进度由真实事件驱动；错误给出失败对象、动作和下一步；高影响操作明确范围 | 普通完成用状态播报；需立即处理的错误用告警。不要逐 Token 播报；模态关闭后恢复焦点 |

## 9. 评审与验收场景

| 场景 | 通过条件 |
|---|---|
| 全新用户首次启动 | 两种桌面入口均能读到签名引擎目录；有目录但无安装时卡片出现“下载并安装” |
| 首次对话 | 从选目录、进入 Office、安装引擎、配置兼容模型到发送，每步均有可见下一步，能看出阻塞原因 |
| 回到原工作 | 输入一段未发送文本，去管理执行引擎再返回；项目、会话、引擎选择和草稿与离开时一致 |
| 切换引擎 | 同一 Office 先使用 Pi 再切 Codex，用户能从第二轮继续引用第一轮内容；重启后能读回消息 |
| 可恢复故障 | 模拟目录离线、下载中断、模型鉴权失败和停止执行；无假成功、无重复消息，草稿和已有安装可恢复 |
| 布局压力 | 以 1440、1320、960、720、390 宽，以及 125%／150% 缩放检查长中文、路径、长模型名；发送、返回和面板开关始终可达 |
| 键盘与触屏 | 仅用键盘完成建会话、选模型、发送、关闭浮层；触屏可执行原悬停操作，输入法确认候选词不会发送 |
| 主题与监控 | 两种主题下焦点、禁用、告警可辨；打开监视器、折叠一组、滚动，连续采样期间位置稳定，关闭不打断 Office |

共享视觉基线见[公共控件样式](../src/view/shared/interface.css)，各页面从[新版视图目录](../src/view/ARCHITECTURE.md)进入。扩展新页面时，应在本文补充入口、主要元素、关键尺寸、状态转换、恢复路径和至少一个可复现的验收场景。

### Office Agent 配置的有效范围

打开对话窗时，主 Agent 从第一个可用引擎及其第一个兼容模型开始，连接器为空。「＋」只修改当前窗口的可用连接器；项目 Skill 可按任务匹配、通过 `/` 选择或由用户链接。入队后保留当时的选择，重开窗口不恢复临时选择。组织成员在创建时使用相同的默认引擎和模型，固定 Skill 和连接器初始均为空；随后在成员设置中独立保存。
