# CBIM Assistant 0.1.0

首个 Windows x64 桌面正式版本。

## 新功能

- 通过安装程序安装 CBIM，工作区、对话历史和设置独立保存在用户目录。
- 软件内发现新版提醒、查看更新日志、手动下载，以及确认后重启安装。
- 对话加号菜单提供「BUG 反馈」「需求许愿」，通过内置 Skill 收集指定格式的上下文。
- 授权 GitHub 后，反馈直接创建到 nan023062/cbim 的 Issue；提交成功不追加结果消息，后续改进通过版本日志发布。
- 包含已有工作区、团队／业务知识、模型配置、主会话及受控成员执行能力。

## 使用说明

- 模型需要用户在设置中配置可用供应商；反馈使用用户自己的 GitHub 授权。
- 新版仅提醒，用户点击才下载；不会在退出或下次启动时自动安装已下载更新。
- 首版 Windows 安装包未配置代码签名，系统可能显示未知发布者。仅从 nan023062/cbim 的 desktop-v 发布下载，并核对 SHA-256。
- 当前仅发布 Windows x64；macOS、Linux、通用服务器账号和开发岗位自动化尚未交付。
- 原 Python 内核 v1.x 为独立历史通道，本安装包不负责其迁移。
