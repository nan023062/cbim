# CBIM Assistant 0.1.1

## 改进

- 版本与更新移到左下角账号菜单，可查看当前版本、检查新版和打开“最近一次更新”。
- 没有新版时也能查看当前安装版的更新日志；发现新版后，可分别查看新版说明与当前版本日志。
- 更新弹窗保留当前页面和未保存内容，关闭后回到原入口；下载期间可以关闭弹窗，稍后继续查看进度。

## 修复

- 修正“BUG 反馈／需求许愿”工具不可用时一律要求重新登录 GitHub 的提示，区分授权等待、本机连接状态和需要开启新一轮的情况。
- 增加反馈工具可用性与加载清单诊断，帮助定位无法提交的问题。已填写的反馈上下文继续保留，提交结果未知时不会自动重复发单。

## 使用说明

- 更新仍由用户手动下载，下载完成后再次确认重启安装；退出或下次启动不会自动安装。
- 使用 0.1.0 时，可从设置中的“版本与更新”升级；升级后从左下角账号菜单查看版本和更新日志。
- 当前发布 Windows x64 安装包，尚未配置代码签名，系统可能显示未知发布者。请从 nan023062/cbim 的 desktop-v 发布下载并核对 SHA-256。
