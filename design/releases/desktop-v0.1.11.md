# CBIM 0.1.11

Windows x64 未签名个人开发版，作为 A（0.1.10）→ B（0.1.11）安装版体验测试的目标包。Windows 可能显示未知发布者或 SmartScreen 提示，请核实来源。本地候选不代表已经公开发布或通过真实安装升级验收。

本版相对 A 只更新版本号和本版日志，产品源码、引擎、依赖与更新通道保持一致，以便观察小改动时后台预下载和安装包差分的实际表现。

在 A 中发现 B 后，后台下载并校验，用户明确点击“重启安装”才停止任务、运行原 NSIS 安装器并重启。普通退出不安装，完整有效缓存可复用；缺少旧包、blockmap 或 Range 不可用时回退全量，最终校验完整包。

公开通道仍固定为 `nan023062/cbim` 的稳定 `desktop-v<版本>` Releases。私下验收需由外部测试工具在隔离测试进程中提供本地更新响应，或手动运行 B 测覆盖安装；不能把手动安装等同于后台下载、差分或公开分发验证。应用身份、EXE 名和用户数据目录不变。
