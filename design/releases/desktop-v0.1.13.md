# CBIM 0.1.13

Windows x64 未签名个人开发版。Windows 可能显示未知发布者或 SmartScreen 提示，请核实下载来源。实际公开状态和验收结果以本版本发布页为准。

本版纳入已合并到 develop 的源码模块整理：执行与模型契约归属 Core，具体引擎适配集中到 engines，预算、证据、派发及存储按职责定位。同步打包入口与真实调用方，保持原有应用身份、EXE、用户数据、IPC、权限和更新通道。

继续使用后台预下载与显式“重启安装”：准备完成前可以继续工作，普通退出不会自动安装。0.1.12 已修复旧安装包缓存目录，本版用于通过真实公开通道验证 0.1.12 → 0.1.13 的增量下载；实际请求数、传输量和节省比例以发布验收报告为准，不预先保证测试结果。

差分下载复用本机准确旧安装包和 blockmap；缓存缺失、损坏或服务端不支持时仍可能回退全量，所有路径都校验最终完整安装包。安装后的缓存仍保存完整包，NSIS 解压与安装方式不变。0.1.10 / 0.1.11 旧客户端升级仍可能完整下载。

本次源码整理不表示历史隔离恢复竞争或其它架构问题已修复，原审阅记录和验证边界保留。
