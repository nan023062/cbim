# CBIM 0.1.14

Windows x64 未签名个人开发版。Windows 可能显示未知发布者或 SmartScreen 提示，请核实下载来源。实际公开状态和验收结果以本版本发布页为准。

- 修复发送对话时统一查询工具的嵌套 Schema 引用错误，避免供应商因工具定义无效返回 HTTP 400。
- 修复首次模型请求失败后重发出现“原生会话身份记录与恢复文件不一致”。对没有回复或工具操作的已封存普通主聊天失败，显式重发可复用可靠会话，或转交原输入创建原生上下文；支持继续当前引擎及切换引擎，保留原对话和失败历史。
- 继续严格拒绝不完整日志、未决工具和不匹配的原生身份；不会自动重放旧业务或隐藏真实供应商错误。

继续采用后台预下载和明确点击“重启安装”。普通退出不会安装，完整有效的缓存可在重开后复用。本次验证范围为真实公开 0.1.13 → 0.1.14，实际增量传输结果见发布验收记录。

增量下载依赖准确旧安装包及服务端 Range 支持，缓存缺失、损坏或网络不支持时仍可能回退全量。最终都校验完整安装包；缓存大小和 NSIS 解压安装方式没有改变。
