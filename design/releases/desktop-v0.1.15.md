# CBIM 0.1.15 · 分层更新与启动优化

- 更新入口移到侧栏用户栏右侧：悬停查看当前/可用版本和进度，准备完成后满环呼吸，点击才安装；主题切换保留在账号菜单。
- 首次迁移到 C/R/E 更新架构。C 是基础程序版本，R 是编译后的业务脚本、界面与资源版本，外部 Agent 引擎以独立 E 包按需下载。
- 后续兼容资源更新会在后台下载、解压和校验，点击后短重启，不再运行整包安装器。Electron、原生基础或固定启动器变化时仍需要冷更安装。
- 移除固定两秒等待，先显示主窗口，再恢复工作区；首次使用引擎时在更新图标中显示准备进度。首次引擎下载需要联网。
- 更新不会自动重放任务；保留原用户目录。更新候选接触数据后发生启动问题时进入恢复界面，不用旧代码自动打开可能已变化的数据。跨引擎包恢复不兼容的原生会话时保留历史并提示新建对话。
- 修复 Codex 工具交互中断后原生会话文件未及时登记的问题；对无法继续的旧历史提供“查看原运行”和“新建对话继续”入口。

本版冷包为 **C 0.1.15 / R 1**，旧安装仍需先完成本次整包升级。首版采用完整的小型资源 ZIP，未实现文件级差分、主进程无重启热替换或跨引擎历史自动迁移。

Windows 安装包仍为**未签名**的个人开发发行，可能出现未知发布者或 SmartScreen 提示。资源清单使用独立 Ed25519 签名验证来源与完整性，该签名不等于 Windows 可信发布者证书。
