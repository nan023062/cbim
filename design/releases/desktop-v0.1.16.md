# CBIM Desktop 0.1.16

本版本为 Agent Team 会话、话题与办公室场景更新。固定启动器已变化，因此通过新的 Windows 安装包更新 C；不以旧 C 的资源更新替代。

- 每个主会话对应独立办公室，同一办公室中的每个 Agent 保留一个逻辑子会话；任务运行和原生上下文独立管理。
- 用户新任务按话题排队，成员回传进入所属话题；用户可选择话题补充需求，系统暂停相关执行并由主 Agent 重新协调。
- 成员只使用当前话题上下文，主 Agent 可按办公室、话题及原内容引用读取历史。
- 任务视图默认展示办公室、人物及当前模块工位；派发和回传驱动人物往返，可从人物入口返回对应对话。
- 已完成、已撤销任务折叠到历史；支持浅色、深色、窄屏及减少动画偏好。

Windows 安装包未签名，系统可能显示未知发布者提示。资源清单继续使用原 Ed25519 签名；两种签名用途不同。本说明不表示候选已公开或全量验收通过，实际安装与升级证据以对应版本验收记录为准。
