# CBIM Desktop 0.1.17

本版是官方领域 Agent Loop 引擎架构的首次冷壳迁移候选。

- 引擎与模型设置分离。Agent 按引擎支持的协议和模型角色选择，主对话与主 Agent 使用同一配置。
- 官方引擎支持独立版本、共享缓存和受控安装、更新、停用、移除；展示业务专长及可用模型。
- Pi、Claude Code、Codex 与自定义记忆引擎统一包协议。模型/历史声明不匹配时拒绝启动，不静默换包或自动重试。
- 记忆引擎需要生成模型与向量模型，支持带出处检索和受控知识修改；重复调用、无进展超时、总时限与未知结果均有停止边界。
- 正式知识仍由 CBIM 管理，向量索引是派生数据；知识提交后索引失败不自动重放原写入。旧引擎历史不自动迁移到新包。

Windows 安装包沿用未签名个人开发模式；资源清单仍使用原 Ed25519 身份签名。当前为验收候选，本说明不表示已发布、所有外部模型通过或公开升级通道已切换。
