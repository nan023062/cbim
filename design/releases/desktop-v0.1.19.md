# CBIM Desktop 0.1.19

- 统一界面图标、状态提示、按钮、表单、帮助与明暗主题，改善窄窗口布局和减少动效体验。
- 补充设置与页面切换的未保存输入提示，保留当前办公室/对话双模式、独立频道草稿和 Agent 工作记录。
- 对主要页面按需加载并拆分公共依赖，减少首次加载体积；页面加载失败提供独立重试入口。
- 明确 CBIM 是本地/多端 AI Native 工作流工具。内置流程围绕用户与 Agent 的任务执行、交接和验证；不新增多人邀请、人员在线状态、独立账号或协作服务。

工程业务的团队协作未来通过插件、链接器接入 P4、Git、飞书等外部工具；这是扩展方向，不代表本版新增这些接入或完整多端同步能力。设计原型中的聚合页面不等于已接入生产功能。

Windows 安装包未签名，发布者未验证，Windows 可能显示安全提示。0.1.19 冷包固定新的 Ed25519 资源签名公钥，后续同 C 的资源更新沿用该身份；旧版本通过完整安装包升级进入新身份，旧资源通道不变。资源签名不等于 Windows 发布者签名。
