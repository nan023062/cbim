# CBIM Assistant 0.1.2

本版为 Windows x64 未签名个人开发发行版。安装时可能出现未知发布者或 SmartScreen 提示，部分安全策略可能阻止运行；请核实下载来源。后续取得证书后将通过更高版本切换到签名发行。

## 改进

- 对话输入区可选择自动模式或团队模式。自动模式为尚未配置岗位或模块的项目提供执行兜底，团队模式保留明确的负责人协作；任务授权与验收要求继续生效。
- 主对话直接展示计划、成员分工、执行步骤、工具状态和待审阅成果，失败提示更清楚。
- 支持重命名、移除对话条目，改进工作区折叠、菜单位置和运行状态提示。
- 统一应用、窗口、安装器与官网的 CBIM 品牌图标。

## 修复

- 修复新项目负责人下拉列表为空、无法继续配置的问题。可从可用 Agent 登记岗位，选择模型并保存后，再设置模块负责人。
- 修复部分 Windows 环境中隔离执行程序初始化失败的问题，继续保留文件、网络和进程资源限制。

## 更新方式

- 本版面向 Windows x64。已安装 0.1.1 的用户可从左下角账号菜单检查更新。
- 下载完成后，点击“停止任务并重启安装”进行升级；工作区、设置与对话数据按原更新流程保留。
- 新版提醒由联网运行中的安装版检查更新后显示，下载和重启安装均由用户确认。
