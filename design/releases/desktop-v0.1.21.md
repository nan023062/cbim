# CBIM Assistant 0.1.21

- 主 Agent 采用连续对话；调用执行 Agent 作为普通工具逐层展开。
- 支持不同模型及引擎递归调用，共享根预算并按实际模型计费。
- 执行 Agent 可暂停原调用向直接调用方求助，答复后续跑原任务；支持逐层转问和停止传播。
- 引擎选择、安装、更新与进度统一放入对话下拉菜单，移除设置引擎分页入口。
- 全界面普通文字统一字号与字重；主对话、子 Agent、工具结果和状态使用一致排版，代码字号独立设置。
- 修正长任务目标整段加粗及窄屏外观设置挤压，补齐逐页明暗主题截图。
- 保留 Flow C 图标、assets 运行资源、独立引擎缓存与已签名资源校验。

Windows x64 安装包未做代码签名，发布者未验证。资源清单仍使用既有 Ed25519 身份签名。进程重启后的未知暂停不会自动重建，旧运行汇总预算不支持递归；不增加多人协作服务。
