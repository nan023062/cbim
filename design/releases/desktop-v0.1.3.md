# CBIM Assistant 0.1.3

本版为 Windows x64 未签名个人开发发行版。Windows 可能显示未知发布者或 SmartScreen 提示，部分安全策略可能阻止运行；请核实下载来源。后续取得证书后将通过更高版本切换到签名发行。

## 改进

- Auto 模式可直接开展实现与验证，项目根始终可见；正式团队协作继续保留责任、权限和成果验收约束。
- 在模块卡片直接选择负责人，新增、编辑和删除使用图标操作；图内提供展开、折叠和字号控制，团队树突出项目自定义组织。
- 工具调用、执行状态和成员过程融入对话，保留按需展开详情和原任务定位。
- BUG 反馈与需求许愿只需一句描述，其余信息可自愿补充。
- 统一「版本与更新」入口，联网运行时每分钟检查新版，并在用户菜单显示提示。用户点击下载后自动校验、停止任务、安装和重启，失败可明确重试。

## 修复

- 减少长对话输入时对历史消息的重复渲染，改善逐键输入卡顿。
- 修复文字与工具通过不同通道返回时的显示顺序，按原调用关联呈现执行过程。
- 负责人保存结果未知时保留查询入口，避免重复提交；界面切换不擅自继续后续写入。

## 更新方式

- 已安装 0.1.2 的用户从左下角账号菜单检查更新，下载后仍需点击「停止任务并重启安装」。升级到本版后，今后的更新才采用点击下载后自动安装重启的交互。
- 点击下载前请保存未提交编辑。普通退出会取消尚未开始的安装；工作区、设置和对话数据沿用原更新流程。
- 关闭应用或离线时不会即时收到新版提示；更新不会代替用户自动开始下载。
