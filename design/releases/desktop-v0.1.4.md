# CBIM Assistant 0.1.4

本版为 Windows x64 未签名个人开发发行版。Windows 可能显示未知发布者或 SmartScreen 提示，部分安全策略可能阻止运行；请核实下载来源。后续取得证书后将通过更高版本切换到签名发行。

## 改进

- 废弃真人花名册和独立的真人维护确认。新项目不再创建人员花名册，模块创建和团队派工不再要求登记真人；岗位、模块负责人、模型与权限约束继续保留。
- 旧人员文件和任务中的维护字段保留为历史内容，不自动删除或改写。
- 派工检查同时列出当前可核实的模块、岗位能力及模型缺口，并在缺少岗位时给出桌面登记入口。

## 修复

- 对象预览按 Agent、Module、Skill、Workflow 分别公开可写字段，消除 Schema 与实际字段不一致。模块中文名写在正文一级标题，结构化名称沿用目录标识。
- 模块正文校验返回精确章节标题和可复制模板，桌面编辑与校验使用同一结构。
- 区分负责人已绑定、已有其他责任记录与真实版本冲突，提供对应的查询和恢复步骤，避免重复设置。
- 实例变化时说明如何获取新 instanceId；工程选错另行提示，未知提交仍先核原回执。

## 更新方式与已知限制

- 0.1.3 用户点击「下载更新」后自动校验、停止任务、安装和重启；0.1.2 及更早的安装版仍需按原界面再点击重启。下载前请保存未提交编辑。
- 普通退出会取消尚未开始的安装。工作区、模型配置和对话数据沿用原更新流程。
- 反馈工具缺失、选择卡偶发 fetch failed 及实例重启的现场原因尚未复现，本版不宣称解决这些网络或进程异常。
