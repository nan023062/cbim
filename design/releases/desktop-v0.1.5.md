# CBIM Assistant 0.1.5

本版为 Windows x64 未签名个人开发发行版。Windows 可能显示未知发布者或 SmartScreen 提示，部分安全策略可能阻止运行；请核实下载来源。后续取得证书后将通过更高版本切换到签名发行。

## 新增

- 在 Pi 之外接入 Claude Code 和 Codex 执行引擎，随安装包提供独立运行资源。
- 大模型配置可选择执行引擎；Agent 默认配置、项目岗位和主 Agent 对话栏支持引擎、模型两个下拉菜单，选项来自用户已启用的大模型配置。
- 主对话可切换引擎，各引擎保留自己的原生会话，通过公开对话内容接续上下文；项目岗位继续使用独立冻结的模型配置。

## 改进

- 未配置自定义负责 Agent 的模块由主 Agent 在原会话直接执行，不再要求先登记默认执行岗位。Auto 和 Team 模式均遵守本轮读写权限、审批与证据要求。
- 内置默认执行 Agent 不再用于新建或派发，原有历史仍可查看。
- 三种引擎共用内部工具授权、请求预算和运行回执，不将模型回合结束视为业务验收通过。

## 更新方式与已知限制

- 0.1.3、0.1.4 用户点击「下载更新」后自动校验、停止任务、安装和重启；0.1.2 及更早的安装版仍需按原界面再点击重启。下载前请保存未提交编辑。
- Claude Code 当前要求 Anthropic Messages 配置，Codex 当前要求 OpenAI Responses 配置；旧配置缺省沿用 Pi。
- Claude Code 与 Codex 支持消息排队，暂不支持运行中插入。Claude Code 使用自身压缩策略；Codex 专用远端压缩端点尚未接入。
- 普通退出会取消尚未开始的安装；工作区、模型配置与对话数据沿用原更新流程。
