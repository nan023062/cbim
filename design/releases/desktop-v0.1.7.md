# CBIM 0.1.7

Windows x64 未签名个人开发发行版。Windows 可能显示未知发布者或 SmartScreen 提示；请核实下载来源。后续签名发行使用更高版本。

## 新增

- 对话固定「自动化」页签：绑定当前工作区，选择默认主 Agent 或团队岗位、模块、Workflow、Skill、提示与权限；支持手动、间隔、每日和一次计划。运行历史可打开真实会话，暂停/删除停止当前任务。
- 团队与业务架构采用文件夹树，知识文件可预览、编辑并自动校验；提供一键团队/业务架构治理。
- 未指定模块负责人时依次解析最近父级、主 Agent 根据模块/岗位知识匹配、默认主 Agent；失效的明确岗位配置会报告缺口。

## 修复与优化

- 知识提交回执与业务目标验收分别展示，校验未通过显示完整问题；只读核实与处置历史入口更明确。
- Pi、Claude Code、Codex 独立于供应商配置，主对话与主 Agent 设置共用同一配置；模型按引擎支持的接口协议筛选（延续 0.1.6 的正确行为）。
- 拆分知识查询、历史存储、请求预算端口、共享执行展示与类型化配置 IPC，减少跨层依赖，保持含类型引用的依赖图无环。
- 清理废弃高级知识管理、直属内容开关、顶部运行绿点及详情按钮；窗口标题简化为 CBIM，设置入口保留在工作区菜单。

## 使用说明

自动化仅在 CBIM 运行且工作区打开时触发；错过的时刻不补跑，同项不会重叠，未知结果不自动重试。需要审批或补充时请打开对应会话处理。执行结束不等于业务验收通过。更新保留原应用身份、数据目录和安装通道。
