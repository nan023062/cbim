# CBIM 0.1.8

Windows x64 未签名个人开发发行候选。Windows 可能显示未知发布者或 SmartScreen 提示；请核实来源。本说明不代表候选已公开或安装升级验收已通过。

## 修复与优化

- 对齐 0.1.7 的发布代码与架构整改，保留自动化、统一主 Agent 引擎/模型设置、模块负责人解析和知识文件树。
- 桌面全部 172 项 IPC 操作统一关联请求与响应类型，新增自动化与主 Agent 设置使用同一解析入口；未知操作、多余请求字段与失效工作区身份仍明确拒绝。
- 知识查询、预算事务、引擎能力和历史存储沿明确端口组合；共享执行展示统一到同一模块，业务恢复控制留在任务层。
- 同步分层检查、源码注释和架构类图；修正旧桌面验收脚本，使其使用真实运行及原回执。

## 升级范围

候选从已发布的 0.1.7 升级，沿用原应用身份、安装通道与数据目录。验收需覆盖工作区、模型配置、主 Agent 选型、自动化定义、知识文件、已完成会话及本机界面数据，并确认升级不重放业务。实际结果见本次验收报告。
