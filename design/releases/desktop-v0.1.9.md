# CBIM 0.1.9

Windows x64 未签名个人开发版。Windows 可能显示未知发布者或 SmartScreen 提示，请核实下载来源。制品与升级验收结果以公开发布页及本版报告为准。

## 修复与改进

- 主 Agent 可通过受治理的预览、提交与回执工具管理工作区成员；完善状态检查、关联目标的影响预览与重复失败停止，避免把未确认操作写成成功。
- 新增公开网页读取和 Brave 网页搜索。网页内容作为不可信外部资料处理；读取检查公共地址、重定向、robots 与访问频率，搜索需在设置中配置自己的 Brave API Key。
- 支持在对话输入框粘贴图片及本地绝对路径，附件可预览和移除，发送前保留草稿与明确来源。
- 模块、团队与 Skill 的操作收进对应文件树行菜单；统一展开图标位置，移除重复根节点，整理树控制按钮；侧栏标题调整为“团队空间”。
- 修复终端中文输出、会话最终回复展示及模型列表为空时的诊断提示；保持 Claude 协议模型的真实标识。

## 升级说明

从 0.1.8 沿用原应用身份、安装通道与数据目录升级。客户端发现新版后，由用户点击下载，校验完成后自动安装重启；请先保存未提交编辑。普通退出取消尚未执行的安装，下次启动不会自行重放业务。

网页搜索的真实账号和额度取决于用户配置，本次不将替身测试表述为第三方在线账号联调。原有不同引擎的执行与授权边界保持不变。
