# CBIM C 0.1.15 · R 2 — 自动验证、返工与恢复

- 通用代码验证：执行 Workflow 声明的检查命令，绑定源码范围、退出状态和验证结果；失败、超时或验证期间源码变化不能作为通过证据。
- 有界自动返工：最终验收发现可修复问题后交回主 Agent，最多三次；原权限、预算、人工条件和失败证据保留。
- 安全重启接收：宿主意外退出后自动接收可靠完成且尚未回传的成员成果，不重复执行旧成员或未知操作。
- 对齐本地单人/少数人 AI 团队开发方向，移除失效代码与旧文档。

此更新为 C 0.1.15 的签名资源包，沿用原三个引擎版本；准备完成后点击侧栏“版本与更新”重启应用。普通退出不会安装。Windows 冷包仍未签名，资源签名不替代 Windows 发布者签名。

自动恢复只覆盖符合核验条件的已完成成果；执行中、未知、损坏、已停止或需人工决定的状态不会盲目续跑。代码验证只覆盖声明的输入/产物范围，不代表任意项目均已通过完整验收。
