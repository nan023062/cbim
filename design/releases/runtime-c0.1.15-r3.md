# CBIM C 0.1.15 · R 3 — 一份 Key，按引擎适配模型接口

- 同一个供应商只需保存一份 API Key；选择 Pi、Claude Code 或 Codex 时自动选用供应商支持的接口，模型 ID 保持不变。
- 内置 DeepSeek、Kimi 国际 API、MiniMax 国际 API、OpenAI、Anthropic 的官方接口预设。已有 DeepSeek 官方配置无需重新添加供应商；地区、套餐和第三方网关可单独配置兼容地址。
- 设置页可添加自定义兼容接口、限定适用型号，并针对已保存的模型和引擎测试连接，显示实际协议与目标地址。
- 主对话、自定义 Agent、岗位登记和模块负责人选择共用兼容性规则，减少界面可选但启动协议不匹配的情况。

这是 C 0.1.15 的签名资源更新，沿用已有三个引擎版本。准备完成后点击侧栏“版本与更新”重启应用，普通退出不会应用更新。Windows 冷安装包仍未签名，资源签名不替代 Windows 发布者签名。

自动适配使用供应商原生兼容接口，不转换模型或协议；未识别的地址需显式配置。连接测试发送少量文本，可能产生费用，不代表工具、推理及流式能力均已验证。
