# CBIM C 0.1.15 · R 4 — 工作流续接与执行中断修复

- 目标等待用户补充时，在对话框发送文字或附件会直接补充并继续原目标。通信结果未知时保留原请求，避免重复排队。
- Pi、Claude Code、Codex 按实际执行进展延长当前运行期限，默认连续 30 分钟没有可观察进展才中断。空输出、重复状态和重试通知不续期；单个工具自身的时间限制仍然保留。
- 任务卡展示可识别的具体中断原因。同一目标累计 3 次成员失败或中断后停止自动接续，换任务编号、穿插其它成功任务或重启应用不会清零；已有在途执行按原流程收尾。
- 成员交付先由主 Agent 审阅，接受后再启动依赖任务；保留原待办，减少重复派发。
- 工具缺少工作区身份时先取得当前身份，可缺省字段使用已声明默认值。缺参提示列出需补字段，减少原始校验 JSON 和不适用的副作用核实入口。
- 修复 Claude 工具 Schema 兼容性和 Windows 原生工具路径处理，改进模型输出上限与中断诊断。

这是 C 0.1.15 的签名资源更新，沿用已有三个引擎版本。后台准备完成后点击侧栏“版本与更新”重启应用；普通退出不会应用更新。Windows 冷安装包仍未签名，资源签名不替代 Windows 发布者签名。

停止和中断不代表操作没有生效，请核实未确认的产物后再决定下一步。更新保留历史记录，不自动重放已中断任务；长时间没有输出的工具仍可能触发无进展超时。
