# CBIM C 0.1.17 / R3 · 双态交互区与频道聊天

- 交互区默认显示对话，右上角图标可切换办公室；侧栏选择 Agent 时保留当前模式，办公室突出对应成员。
- 自动化移至右侧扩展区。主聊天集中呈现用户与主 Agent 的公开消息及频道入口。
- 打开频道后，左侧保留主聊天，右侧显示频道子对话。草稿、附件、滚动和展开状态分别保存，切换或关闭频道后可恢复。
- 成员对话页改为只读工作审阅，展示任务、工具过程、公开执行说明和与主 Agent 的汇报；需要补充时可返回所属主频道。
- 频道补充继续沿用原目标接续、暂停重规划或关联后续任务规则。未知提交结果保留原请求，不自动重复发送；临时附件导入失败仍可编辑和重试。

主聊天与频道的界面独立，任务仍由同一主 Agent 按现有规则协调；查看或切换视图不会启动、取消或重启任务。

本次是 C 0.1.17 的 R3 资源更新，基础程序与四个官方引擎包保持原版本。客户端后台准备完成后，点击侧栏更新图标重启即可应用；普通退出不会应用更新。

Windows 基础安装包仍为个人开发未签名版本；资源清单沿用 C 0.1.17 的 Ed25519 身份签名，资源签名不等于 Windows 发布者签名。
