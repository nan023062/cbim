# CBIM C 0.1.18 / R2 · 全部引擎总览

- 引擎设置默认打开“全部引擎”，集中显示已安装引擎的当前版本、运行库版本、启停和运行占用情况。
- 运行、准备进度及异常分别显示，状态自动刷新；点击引擎即可进入详情并管理。
- 已移除、只留下历史缓存的引擎不列入已安装列表；总览在窄屏下纵向排列。

本次是 0.1.18 的 R2 资源更新，基础安装器和四个官方引擎包保持原版本。后台准备完成后，点击侧栏更新图标重启应用；普通退出不会应用更新，已有引擎安装状态和缓存继续保留。

Windows 基础安装包仍为个人开发未签名版本；资源清单使用原 Ed25519 身份签名，资源签名不等于 Windows 发布者签名。
