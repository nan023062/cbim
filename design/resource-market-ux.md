# CBIM 资源商城交互方案

浏览与采用流程可在[商城交互原型](resource-market-preview.html)中试用，安装、引用和导入只改变本页示例状态。

## 首页纵览，再进入商品页

从侧栏「资源商城」进入，默认「全部」，同屏呈现引擎、连接器、人力和业务商品。分类页签与搜索组合筛选，支持名称、开发者、资源 ID 和版本号。桌面以多列卡片排布，320 px 下为单列。每张卡展示 Logo 或类别图标、名称和用途，信息行常显类别、免费或带币种的金额、最新发布版本、紧凑安装量。未提供统计时显示「安装量暂无统计」，实测为零时显示「安装量 0」。整卡是唯一入口，点击或按 Enter 打开商品页。

「已购」根据付费使用权益显示。「可更新」在本机已有安装、可用新版高于本机最高安装版本时显示，按主、次、补丁号逐段比较。安装新版后，即使项目仍引用旧版，也只保留适用的权益角标。角标排在卡片右下的独立行，可换行，作为按钮的无障碍描述读出。原型使用示例数据，脉冲执行引擎初始并列「已购」「可更新」，交互评审员购买前仅显示人民币价格，卷册文档桥显示免费。

详情页展示商品标识、功能、预览、开发者及逐版本的更新记录。在「获取与使用」中只显示一个当前主操作。「画帧解析器」模拟购买后可安装并在示例项目引用，默认选中最新版本。「脉冲执行引擎」从 v1.1.0 更新时，安装和校验成功后，当前项目引用同步切到 v1.2.0。失败保留原引用，重试沿用所选版本和购买权益。返回商城时恢复分类、关键词、滚动位置和原商品卡的键盘焦点。

分类标题旁提供次级入口「发布资源」。进入后选择资源包，核对资源 ID、版本、文件清单、依赖和共享范围，再确认上传。收到发布成功回执后提供「查看已发布版本」。版本冲突时保留表单，提示填写新版本号。

## 选版本，再决定如何使用

详情先显示资源名称和发布者，再显示版本选择器、包大小、依赖和当前项目名。首次浏览默认选中最新发布版；从项目查看已用资源时定位到项目记录的版本。版本列表分别标明「最新发布」「本机已安装」及「本项目使用中」，允许多个本机版本并存。选择版本只刷新详情和按钮。

| 分类 | 详情主操作 | 成功后 |
| --- | --- | --- |
| 引擎、连接器 | 主按钮同时写明安装或更新、目标项目和所选版本。连接器缺授权时先安装到本机，再确认授权并引用。 | 成功后当前项目保存精确版本引用。其他项目独立选择版本，进行中的任务继续使用启动时的版本。 |
| 人力、业务 | 显示「导入到〈项目名〉」，确认页列出所选版本和将创建的岗位、技能或业务节点。复用已校验的本机包，缺包时先下载校验。 | 创建带独立 ID、来源和版本的项目副本，提供「查看导入结果」。再次导入创建另一份副本；更新已有副本时选择具体实例，查看差异并确认拟合并的改动。 |

无活动项目时，共享资产仍可安装；涉及引用或导入的按钮显示「选择项目」，选好后返回原资源和版本。项目只读时保留浏览，在操作处说明需要可写项目。清理模板缓存后仍可打开项目副本；共享资产清理预览列出占用版本的项目和任务。

### 卸载已安装版本

首页将当前目录与账号已购、成功卸载的历史商品按「类别＋资源 ID」合并。搜索框旁的状态筛选可与分类、关键词同时使用。「帧序列阅读器」演示已购未装，「卷册文档桥」演示免费已卸载，「影像注释引擎」同时显示「已购」「已卸载」。仅当成功卸载且本机安装版本数为零时显示「已卸载」，重装后立即移除该角标；已购权益继续保留。返回时若商品已不满足筛选条件，焦点回到状态筛选器。同一浏览器、同一地址重新打开原型会恢复演示记录。

引擎或连接器的详情仅在所选版本已安装时显示次级操作「卸载所选版本」。确认窗列出资源、版本和当前项目的处理结果。若项目正引用该版本，回退到本机剩余可用版本中版本号最高的一版；若无可用版本，清除引用。卸载其他版本时保留当前引用。确认成功后同步刷新安装列表、项目引用和商城角标；取消或失败时保留原状态，失败可在确认窗重试。购买权益保留，可再次安装。人力与业务的独立项目副本由项目管理。

## 反馈与窄屏

- 目录加载中显示读取状态；分类为空显示「暂无已发布资源」，搜索无结果提供「清除筛选」。目录连接失败时显示「无法连接资源商城」与「重试」，已安装资源仍可在本机使用。
- 下载、校验、安装或导入的进度紧邻当前按钮，同一操作期间阻止重复提交。失败保留所选版本，指出失败阶段并提供对应重试入口。校验失败的包须重新获取；项目引用缺包时按原版本和摘要恢复。
- 320 像素宽度下，分类分两行，卡片单列，点卡片进入全宽详情。版本选择器、目标项目和主按钮纵向排列，长 ID 可换行。返回后焦点回到原卡片；进度及错误以文字播报。

## 共用控件与扩展

| 状态及进入／退出 | 色彩、图形与动效 | 反馈位置、示例文案及下一步 |
| --- | --- | --- |
| 默认，打开目录或指针移出 | 表面 `--surface`，名称 `--accent`，说明 `--muted`，静态 | 整卡可打开商品页，名称与价格始终可见 |
| 悬停，指针进入／离开卡片 | `--hover` 底色与 `--control-line` 边线，120 ms | 整卡作为一个可访问按钮，触屏点按同一区域 |
| 焦点，Tab 移入／移出 | `--focus` 2 px 轮廓，立即出现 | 图标 tooltip 在按钮旁显示，焦点退出或 Esc 收起；触屏显示等义操作文字 |
| 选中，切换分类或版本 | `--selected` 底色，当前分类细线取暖橙 `--warning`，`tween-control` 120 ms | 分类名保留原位，读屏宣告选中；方向键换分类。版本下拉显示具体版本 |
| 禁用，项目只读或版本已引用，条件解除后恢复 | `--muted`，按钮原生禁用，静态 | 操作旁常显「项目只读」或「示例项目正在引用」；可选择其他项目／版本 |
| 下载、更新或上传，自请求开始至回执 | `--text` 和时钟；不定进度用 `tween-pulse` 1.2 s，定量进度用 `tween-progress` 250 ms | 主按钮旁报「正在下载并校验版本…」「正在准备更新…」「正在上传示例包…」，锁定重复操作。减弱动效时保留时钟与阶段文字 |
| 成功，收到回执至下一操作 | `--success` 和勾号，静态 | 操作旁「✓ 已安装 v1.2.0」，更新资源行，提供「在项目引用」或「查看副本」 |
| 失败，操作出错至重试或用户主动关闭 | `--danger` 和叉号，静态 | 操作旁持续展示「× 下载失败，连接中断」，播报原因；「重试」沿用原版本 |
| 离线，目录连接失败至恢复 | `--warning` 和警示图形，静态 | 目录或操作处「⚠ 商城离线」，提供重试；本机已安装版本继续可选 |
| 购买或授权，从缺少权益／账号到确认回执 | 文本 `--text`，缺授权用 `--warning` 加锁标；确认窗 `tween-panel` 220 ms | 详情显示「购买 ¥20」或「需要账号授权」。确认窗列出价格、范围或权限；可取消，模拟成功后才显示安装或引用 |

确认窗按 Esc 关闭并恢复触发点焦点。系统减弱动效时所有过渡立即完成；图标、文字、焦点环和主操作继续显示。原型的「演示条件」可选择下一次失败、离线或预览减弱动效。

分类采用客户端 Tabs 的选中底色、方向键和 Home／End 行为。页签底部的细暖橙线标记当前分类，键盘焦点独立使用主题焦点环。结果行沿用列表按钮，发布为页首次级操作，版本详情内只强调当前可执行的主按钮。触屏目标至少 44 px。确认窗、按钮和行内提示沿用客户端动效，开启减弱动效时立即切换。

新类型、媒体预览和收费资源沿用上述商品卡、页签、详情页和按钮。价格与播放状态用文字标识，预览控件位于详情内容区，购买或采用操作位于「获取与使用」区。尺寸、主题和交互状态见[桌面交互规范](desktop-ux-spec.md)。

新增类型沿用分类、搜索、版本和详情入口，按所选版本提供适合的预览。例如，人力模板可预览岗位与技能，业务模板可预览流程，多模态引擎可展示支持的输入输出类型及对应的图像、音频或视频样例。缺少适配的预览方式时展示说明和文件清单。

用户发布引擎、连接器、人力或业务资源时均可选择免费或收费。收费资源在列表标价，详情说明所选版本的价格与使用范围。尚未获得使用权时，主按钮显示「购买」及金额；取得使用权后恢复该类型的安装或导入操作。

资源归属与版本规则见[资源体系设计](resource-system.md)。类型、预览策略、多模态能力和收费机制见[商城扩展设计](resource-market-extension.md)。
