# 任务依赖修订支持范围

对应 R04。以下按实际协议区分允许的调整和必须拒绝的历史变更；本表不授予执行、恢复、转派或验收权限。证据入口为[单条追加](../verification/queued-dependency-addition-20261107.md)、[多条原子修订](../verification/queued-dependency-revision-20261108.md)和[已放弃检查点来源](abandoned-checkpoint-dependency.md)；可靠失败/求助替换已有[历史验证](../verification/queued-dependency-replacement-20261107.md)，已放弃检查点分支已通过[Step43验证](../verification/abandoned-checkpoint-dependency-20261108.md)。

| 调整 | 已实现协议 | 保持及复核 |
| --- | --- | --- |
| 先建立后继，再补一个未执行前置 | add_dependency | 两端及完整后继闭包未领取；当前图防环、知识/岗位/流程有效；保留原信封/实例 |
| 删除未执行来源的边、换成其它未执行来源、同目标组合增删 | revise_dependencies | 一次最多32退役/32新增，按修改后的完整图防环；旧边退役不删除；完整闭包一次事务，不造候选 |
| 可靠失败或安全求助来源，以后来真实候选接替 | replace_dependency | 原来源已可靠结算，新候选覆盖原模块、当前知识及完整证据；目标与全部后继未领取，原事实保留 |
| 已明确放弃的可靠检查点来源，以后来真实候选接替 | replace_dependency | 额外核原检查点证明、放弃、原完成段/通道/租约及已处置预约；普通取消不等于明确放弃 |
| 一次调整后仍有其它未满足前置 | 所有调整共用当前图/领取 | 保持 waiting，不忽略其它门禁；最后待办满足才可 queued，仍等主轮结束及实际准入 |
| 保存后坏回包、重复命令、停止/关闭/重启 | 原命令与不可变审计 | 原保存与原工具失败分开，只读核实；同键不多写，停止/重开不自动领取或重发 |

以下不属于可以修改的待办依赖：目标或其启用后继已领取/运行/结算；跨周期、当前岗位或知识不匹配；普通取消/中断/未知来源没有可靠替代资格；删除已执行来源而掩盖事实；把历史退役边重启；修改原目标、权限或角色；用成功维护回执冒充业务候选。需要改变执行责任或目标时另建任务，已存在的完成候选可在新任务派发中按原协议作为前置。可靠失败、求助或明确放弃来源的替代还须在目标完成审阅中显式记录 `superseded`。

依赖修订保留尚未启动任务身份，并不赋予旧失败/关闭任务复活能力。跨重启保留待办、成员再次检查点、通用等待和交接属于 R05；不以本表把这些生命周期要求标为完成。执行外部效果的恢复及其可靠证明仍属于 R03/R07/R13。
