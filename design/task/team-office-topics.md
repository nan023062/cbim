# Agent 对话与工具执行设计入口

2026-11-15：原“主会话办公室、任务话题与团队对话”设计已替换。保留路径供旧链接定位，不再保留旧频道中心规则作为当前需求。

主界面是用户与主 Agent 的连续对话。主 Agent 调用执行 Agent 与普通工具使用同一交互；执行 Agent 可以继续调用 Agent 或工具，反馈只返回直接调用方。通过工具条目逐层展开执行对话，用户不直接向执行 Agent 发指令。

Team 配置可调用 Agent、职责与权限，不提供独立聊天模式。深度、并发、预算显示在工具详情，超限返回工具错误，不新增界面概念。
