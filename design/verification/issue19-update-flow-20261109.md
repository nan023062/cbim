## 维护与发布边界

`DesktopUpdates` 拥有整个在途更新操作，`main.ts` 只注入业务排空回调、拒绝安装期间的新业务请求，并在普通退出时及时取消。固定 GitHub 通道、NSIS 清单/摘要验证、应用身份和重启用户目录保持原实现；不会把“开始安装”记录为“升级成功”。

菜单样式和用户栏提示在 `shell/UserMenu`，统一弹窗与本机状态读取在 `frontend/updates`。以后只改呈现无需改下载/排空机制；调整安装策略须覆盖后端时序与退出取消测试。已同步相关源码注释、6 份 ARCHITECTURE、5 份 CONTRACT、README 与发布指南。

发布 Skill 三宿主同步区分旧两步客户端和新自动流程；安装验收脚本仅适配新旧日志入口，其在线路径仍固定旧版 0.1.1，后续发布必须按真实旧版改造并验收。当前公开版本仍为 0.1.2；本轮没有发布、安装、卸载或重启真实用户客户端。新的自动流程尚未做真实 NSIS 跨版本升级验收，必须在下次发行的隔离 Windows runner 完成，不能以本轮替身/便携测试代替。
