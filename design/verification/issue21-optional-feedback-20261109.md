# Issue #21：一句话反馈，补充字段可选

日期：2026-11-09。范围：[Issue #21](https://github.com/nan023062/cbim/issues/21)。

BUG 和需求工具仅要求 `kind` 与非空 `summary`；复现步骤、结果、环境、场景和例子均可省略或留空。缺失主栏目统一为“用户未提供”，用户明确提供的“不清楚”等内容保持原意。仅点击菜单时提示一句描述即可，有简述时直接提交，不要求模板、补填或再次确认。没有自动采集环境、工程或附件。
