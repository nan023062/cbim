## 本轮交付

团队架构维护工作区唯一静态 Team/分组/Agent 与 Skill；业务架构维护工作区唯一领域工程/模块与其自身 Workflow。表单提供增删改查、结构预览与明确提交，模块维护真人及确认记录同事务保存。人才支持完整 Team、单 Agent、单 Skill 跨项目复用；业务模板始终完整发布和应用。导入移除原项目人员、维护关系、连接器与源码定位绑定，需要在目标项目重新确认。

主会话的任务图继续独立：调度节点关联成员实例、目标和目标模块，静态编辑不会创建或重建运行实例，也不会改写会话任务。旧任务的知识基线变更后，执行准备明确拒绝，要求重新准备，不能静默替换原上下文。

## 验证边界

- 本轮跨项目发布/导入实测的是本地仓库；账号登录与中心服务器仍未接入，未进行跨物理电脑验证。
- 便携测试不等于全新 Windows 虚拟机测试，也未验证代码签名与 SmartScreen。
- 静态包限制为 2 MiB、512 个文件，单文件 200000 字符；当前不包含二进制附件。
- 结构、引用和版本检查不等于业务验收；正文的项目适用性仍需 review。资源包不迁移工具执行授权。
