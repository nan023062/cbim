## 发现的问题

1. **命令保护误判，尚未修复。** 两条指定 `index.html` 的非递归 `grep` 命令被拒绝，理由为“请把搜索限定到明确的业务目录，避免递归扫描工作区知识库”。其中包含 `grep -nE 'https?://|src=|@import|<link' index.html`。模型随后使用 Node 成功验证；此结果不能证明搜索规则正确，后续应补充带引号正则和命令组合的路径解析回归测试。
2. **测试环境配置。** 仅复制 `llm.json` 会因缺少 Windows safeStorage 对应的 `desktop/Local State` 而无法解密，首次尝试未启动模型。测试脚本已同时复制受系统加密保护的配置；没有读取或打印明文密钥。
3. **截图超时。** 首轮模型任务已完成，但自动截图超时打断后续断言。随后复用同一产物和日志完成浏览器、重启和任务视图检查，未重新执行生成任务。测试脚本将截图失败作为单独告警。
