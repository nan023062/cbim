# 本地与账号服务器资源仓库

链接器、人才市场、业务模板共用当前身份对应的仓库，自动化仍属于各工作区内部。

## 仓库来源规则

- 未登录：使用本地目录，可在设置中选择或更换。
- 已登录：由账号服务自动提供服务器仓库，不能手填地址和令牌，也不能切回本地。
- 退出登录：恢复上次本地目录，不搬迁、合并或删除资源。
- 登录后服务器尚未提供或连接失败：显示服务器仓库待接入或不可用，不回退本地，不继续使用上一个账号的仓库。

当前账号认证和 CBIM 中心服务器尚未接入，桌面实际使用未登录的本地模式。服务器区域与退出登录为占位，没有模拟登录按钮。

## 使用本地仓库

1. 点击左下角用户栏，在菜单中选择「设置」，或在资源页点击「前往设置」。
2. 在本地仓库区域选择已有文件夹或输入绝对路径。
3. 点击「保存本地目录」。三类资源立即共用该配置。

首次使用会在所选文件夹创建 `cbim-resources.json`，包括版本、稳定仓库 UUID 与资源定义。已存在的文件先验证，不覆盖格式损坏的文件。安装目录、用户运行数据目录及项目 `.cbim/` 不能作为资源仓库。仓库目录本身须已存在，不会因路径输入错误自动创建目录。

支持链接器定义、完整团队、专项 Agent、单个 Skill 和完整业务架构的管理。工作区架构页可生成可移植静态包，发布到同一仓库；人才市场/业务模板页可选择目标工作区，或直接在工作区架构页下载、预览并应用。旧自由文本资源仍可编辑，但只有有效的静态资源包才能应用；旧单模块/Workflow 定义保留，不提供单独应用入口。资源应用不会启动成员、执行 Skill 或安装插件。

## 静态资源的发布和使用

- 团队架构支持完整 Team、单个 Agent 或单个 Skill。独立 Agent 包包含其实际可用的继承 Skill，使能力不依赖原组织路径；与目标祖先同名时校验提示冲突，不静默覆盖。
- 业务架构只能完整发布和应用，包括全部工程、模块及其 Workflow。目标为空时可直接预览新增，已有架构时要求显式整体替换。
- 团队包可作为一个完整子组加入，或显式替换当前团队。Agent/Skill 只新增；目标同名对象拒绝覆盖。
- `cbim-workspace-package` v1 包记录种类、静态文件及内容指纹。只接受定义与 Markdown 正文，检查路径、引用闭合、结构和冲突；包内不含成员实例、主会话、任务、运行记录、真人花名册或配置凭据。
- 发布清除作者、连接器、源码定位及维护关系绑定。业务模板应用后需在目标项目重新确认维护真人和源码目录。正文仍应人工核对，不保证自由文本里不存在项目特有语义。
- 发布不改源工作区；应用先固定源仓库版本、资源内容与目标工作区版本，返回持久化预览计划。只有用户确认后才走知识事务提交，索引一起更新。源或目标变化需重新预览；成功提交重试复用原回执。
- 若正式定义已应用，但空目录清理或后续索引刷新失败，返回 `RESOURCE_IMPORT_APPLIED` 并说明已应用部分；保留当前预览，重试同一计划继续处理，不再次覆盖包内容。
- 替换只处理静态知识，保留真人花名册与业务源码；目录含未知文件时拒绝整体替换。多个主会话继续各自持有动态任务图，静态资源应用不迁移任何运行实例。

## 让此电脑提供服务

在已选定本地仓库的设置中点击「启动仓库共享」。默认只监听 `127.0.0.1`；若明确勾选「允许其他电脑通过局域网连接」，则监听 `0.0.0.0`。端口填 0 时由系统自动分配，也可指定固定端口。

点击「显示连接信息」取得地址和共享令牌。协议客户端可将地址中的 `127.0.0.1` 替换为服务端局域网 IP，并携带同一令牌。桌面未登录用户不再提供手动远端连接入口；本地共享服务本身不是账号认证服务。需要操作系统网络策略允许该端口；应用不会自动修改防火墙。一个令牌允许读写整个仓库，没有多用户角色或只读令牌。

HTTP 仅适合可信局域网；公网部署须在外层配置 HTTPS。客户端支持 HTTPS，但本机共享服务本身不自动签发证书或配置反向代理。服务退出时停止监听，重启不会自动共享，每次重新启动共享会生成新令牌。

## 账号服务接入边界

主进程内部的 setAccountSession 接收未来账号服务确认后的账号身份和服务器信息；没有对应的渲染层 IPC。切换串行执行，先隔离上一个来源并停止共享，再读取账号服务器；只有验证成功才允许资源读写。没有服务器信息时保留服务器占位，连接失败不回退本地。

setAccountSession 不是认证实现，不接受界面伪造登录。当前测试从内部注入会话，使用真实 HTTP 仓库验证自动切换、鉴权、读写、失败隔离与退出恢复；实际登录、会话失效、账号发现和认证刷新需后续账号系统接入。

仓库编辑请求仍携带读取时的身份和版本。切换后的旧编辑不能写入新仓库，服务返回不同仓库身份时拒绝继续使用。

## 存储与一致性

- 本地仓库文件：`<手选文件夹>/cbim-resources.json`。
- 本机连接设置：`<用户主目录>/.cbim/resource-repository-settings.json`。
- 本机设置文件只保存本地目录配置。账号提供的服务器凭据仅保存在内存，重启不会自行恢复登录。
- 旧版远端配置启动时停用并提示，不读取为登录会话，也不自动删除原文件。用户显式保存本地目录后，该设置文件更新为本地配置。
- 历史 `resource-library.json` 不自动读取、迁移或删除。
- 写入使用操作系统互斥、内容哈希版本校验及同目录原子替换。数据来自文件，内存不构成第二套真源。
- 单个仓库文件上限 8 MiB，最多 2000 条定义，单条正文最多 2 Mi 字符；可导入的静态包另限制为 2 MiB、512 个文件、每文件 200000 字符。这是小型团队资源定义库，不是二进制素材仓库。
- 本地跨进程并发通过内核锁协调。未验证跨电脑共享文件系统锁；多电脑应连接 HTTP 服务，不能据此声称支持同时直接写 SMB/NFS 目录。
- 远端请求超时不自动重试写入；结果不明时要求刷新核对，避免重复创建。第一版没有离线写队列、同步、完整版本历史或备份服务。

## 服务接口

所有请求必须携带 `Authorization: Bearer <token>`；服务拒绝带 Origin 的浏览器请求，不开放 CORS。API 不提供文件路径写入或命令执行。

| 方法与路径 | 请求与结果 |
|---|---|
| `GET /v1/resources` | 返回 `{repositoryId, revision, items}` |
| `POST /v1/resources` | `{repositoryId, revision, id?, item:{kind,name,summary,content}}`；无 id 为创建，有 id 为编辑 |
| `DELETE /v1/resources` | `{repositoryId, revision, id}` |

写入成功返回完整新快照。资源条目包含 `id`、`kind`、`name`、`summary`、`content`、`updatedAt`。401 表示鉴权失败，403 表示 Origin 不允许，409 表示版本或仓库身份冲突，400 表示请求格式不合法，413 表示请求过大。客户端每次读取都核验已连接的仓库身份，远端重定向不会携带令牌跟随。

## 验证范围

后端测试使用真实目录和 HTTP 服务验证本地持久化、未登录远端拒绝、账号来源自动切换、服务器占位、鉴权失败后的隔离、退出恢复本地、旧配置停用及资源读写冲突。账号会话由测试内部注入，不能视为真实登录验证。

桌面测试验证未登录设置中无远端选择、地址或令牌输入框，服务器登录占位禁用，三类资源共用本地目录，以及本地共享服务启停和重启配置恢复。

跨物理电脑的局域网、防火墙和公网 HTTPS 部署尚未实测。构建产物按北京时间存放在 build/YYYYMMDD-HHmmss/，最新路径见 build/latest-build.json。
