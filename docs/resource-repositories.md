# 本地与远端资源仓库

第一版无需 CBIM 云端服务器。运行 CBIM 的电脑可以管理手动指定的本地仓库，并按需提供 HTTP 仓库服务；其他 CBIM 客户端可连接该服务。链接器、人才市场、业务模版共用当前选定的仓库，自动化仍属于各工作区内部。

## 使用本地仓库

1. 进入任一资源入口，打开「仓库设置」。
2. 选择「本地仓库」，选择已有文件夹或输入绝对路径。
3. 点击「验证并切换仓库」。

首次使用会在所选文件夹创建 `cbim-resources.json`，包括版本、稳定仓库 UUID 与资源定义。已存在的文件先验证，不覆盖格式损坏的文件。安装目录、用户运行数据目录及项目 `.cbim/` 不能作为资源仓库。仓库目录本身须已存在，不会因路径输入错误自动创建目录。

当前支持链接器、专项 Agent、Skill、业务架构、单一业务模块和 Workflow 定义的创建、编辑、复制定制、搜索、删除。正文为自由文本（Markdown/JSON 等），不代表已通过工作区知识规则校验，也不会自动安装插件、执行 Skill 或应用模版。

## 让此电脑提供服务

在已选定本地仓库的设置中点击「启动仓库共享」。默认只监听 `127.0.0.1`；若明确勾选「允许其他电脑通过局域网连接」，则监听 `0.0.0.0`。端口填 0 时由系统自动分配，也可指定固定端口。

点击「显示连接信息」取得地址和共享令牌。其他电脑将地址中的 `127.0.0.1` 替换为服务端局域网 IP，并填写同一令牌。需要操作系统网络策略允许该端口；应用不会自动修改防火墙。一个令牌允许读写整个仓库，没有多用户角色或只读令牌。

HTTP 仅适合可信局域网；公网部署须在外层配置 HTTPS。客户端支持 HTTPS，但本机共享服务本身不自动签发证书或配置反向代理。服务退出时停止监听，重启不会自动共享，每次重新启动共享会生成新令牌。

## 连接远端服务器

1. 在「仓库设置」选择「远端服务器」。
2. 输入服务根地址（例如 `http://192.168.1.10:43187`）及共享令牌。
3. 点击「验证并切换仓库」。

地址需要是兼容 CBIM Resource Repository v1 的服务，不是任意网盘、Git 地址或网页。客户端先读取仓库并检查协议与身份，验证成功后才保存配置。连接或鉴权失败时保留当前仓库。当前窗口不能切换为连接自己正在提供的服务，继续使用本地模式即可；另一个客户端可远端连接。

切换不复制、合并、搬迁或删除任何仓库数据。资源编辑请求携带读取时的仓库身份及版本；切换后的旧编辑不能落入新仓库。远端地址返回不同仓库身份时会拒绝，需人工重新连接。

## 存储与一致性

- 本地仓库文件：`<手选文件夹>/cbim-resources.json`。
- 本机连接设置：`<用户主目录>/.cbim/resource-repository-settings.json`。
- 远端令牌存于上述本机设置文件，依赖当前用户目录权限保护，不写入仓库、项目知识或日志；未使用系统钥匙串。
- 历史 `resource-library.json` 不自动读取、迁移或删除。
- 写入使用操作系统互斥、内容哈希版本校验及同目录原子替换。数据来自文件，内存不构成第二套真源。
- 单个仓库文件上限 8 MiB，最多 2000 条定义，单条正文最多 200000 字符。这是小型团队资源定义库，不是二进制素材仓库。
- 本地跨进程并发通过内核锁协调。未验证跨电脑共享文件系统锁；多电脑应连接 HTTP 服务，不能据此声称支持同时直接写 SMB/NFS 目录。
- 远端请求超时不自动重试写入；结果不明时要求刷新核对，避免重复创建。第一版没有离线写队列、同步、完整版本历史或备份服务。

## 服务接口

所有请求必须携带 `Authorization: Bearer <token>`；服务拒绝带 Origin 的浏览器请求，不开放 CORS。API 不提供文件路径写入或命令执行。

| 方法与路径 | 请求与结果 |
|---|---|
| `GET /v1/resources` | 返回 `{repositoryId, revision, items}` |
| `POST /v1/resources` | `{repositoryId, revision, id?, item:{kind,name,summary,content}}`；无 id 为创建，有 id 为编辑 |
| `DELETE /v1/resources` | `{repositoryId, revision, id}` |

写入成功返回完整新快照。资源条目包含 `id`、`kind`、`name`、`summary`、`content`、`updatedAt`。401 表示鉴权失败，403 表示 Origin 不允许，409 表示版本或仓库身份冲突，400 表示请求格式不合法，413 表示请求过大。客户端每次读取都核验已连接的仓库身份，远端重定向不会携带令牌跟随。

## 验证范围

后端测试使用真实本地目录和真实 HTTP 服务，验证本地持久化、配置恢复、双仓库隔离、远端增删读写、鉴权失败、过期写入、身份替换、端口占用和关闭服务。桌面测试启动两个独立 Electron 进程：一个服务端，一个客户端，通过实际设置界面切换本地/远端并写入资源，再验证切回与重启。

跨两台物理电脑的局域网、防火墙和公网 HTTPS 部署尚未实测。构建产物按北京时间存放在 `build/YYYYMMDD-HHmmss/`，最新路径见 `build/latest-build.json`。
