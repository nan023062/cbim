# 前端基础类库

前端与后端是独立的域，各自在域内沉淀公共能力。此目录只承载前端低频、可独立验证的机制，不依赖页面、业务控制器、bridge 或后端 foundations；不持有业务状态或通信权限。

当前只有 [utility](utility/CONTRACT.md)，通过其 `index.ts` 提供 JSON 比较、实例订阅集合与异步代次标记。异步代次只判断结果是否仍属于当前生命周期，不取消请求；订阅集合只持有监听器，状态发布、轮询和销毁仍归各控制器。后续同类算法按类别内聚，不能把页面状态机、回执规则或持久化策略机械下沉。后端不反向消费此前端库，通信契约也不作为工具库的转发入口。
