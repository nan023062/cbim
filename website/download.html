从安装到第一轮协作

  1. 安装桌面应用

    下载 Windows x64 安装包，核对来源后按安装向导完成安装。在开始菜单搜索「CBIM Assistant」即可启动。

  2. 配置你的模型服务

    在设置中配置可用的模型服务与相应凭据。模型用量与费用取决于你选择的服务商。

  3. 建立本地工作区

    选择一个项目目录，整理团队角色和项目知识；在对话中提出明确目标、约束和验收要求。

  4. 查看更新，按需安装

    在左下角账号菜单检查新版或查看最近一次更新。点击后才下载，再次确认后才重启安装。

Before you begin

开始使用前，你可能想了解

这个版本包含官网上的新图标吗？

尚未包含。官网和源码已采用统一品牌，当前下载仍指向已发布的 0.1.1。新图标会随后续完成构建、签名与安装验收的客户端版本交付。

软件会自动下载安装更新吗？

发现更高版本时会提醒。只有你点击后才下载，下载完成后再次确认才重启安装；正常退出或下次启动不会自动安装。查看更新日志不需要 GitHub 登录。

在哪里反馈 BUG 或提出需求？

在软件对话窗的「+」菜单选择「BUG 反馈」或「需求许愿」，按 Skill 提示补充上下文。首次需在设置中连接自己的 GitHub 账号，随后直接创建 Issue；后续修复与功能变化统一查看更新日志。提交到公开仓库的内容公开可见，请勿填写密钥或私人资料。

我的项目与对话数据会放在哪里？

工作区以本地项目目录组织。使用模型服务、插件或 GitHub 反馈时，相关上下文会按所选服务的调用发送；这不是完全离线的应用。本站不要求登录、不收集反馈内容，也没有嵌入统计脚本。下载文件与项目文档由 GitHub 提供。

旧的 v1.x 也是这个桌面应用吗？

不是。GitHub 仓库中的旧 v1.x 属于早期 Python 内核通道。请使用本页链接或名称以 desktop-v 开头的桌面发布，避免误下载旧产物。

为什么 Windows 会提示未知发布者？

当前公开安装包没有可信代码签名。签名发布流程已经接入，实际签名版仍等待证书配置与验证。本页不会把未签名的现有文件标成签名版，也不建议关闭系统安全功能。
